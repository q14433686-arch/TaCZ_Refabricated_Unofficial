### 1.2.0+fabric.26.3.R1 — development / test build

This describes the 26.3 feature integration **through PR #124, tested at `a28882da`**. It is not the changelog for the older public 1.1.8 R1-hotfix3 file. Check the build as well as the version string: earlier CI jars can have the same version.

- Pick up an iron block to unlock the gunsmithing table recipe in the vanilla book. The table is made in a 3×3 grid; the guns, parts and ammo are made at their respective benches. Late pack sync now preserves regular server recipes in REI. Filters shared between gun packs combine, and blacklist-only filters no longer empty the remote client's benches. This doesn't restore recipes disabled by the server.
- Browse an expanded default catalog (70 guns, 25 ammo types, 126 attachment entries, plus 5 slot adapters). Use a compatible riser for supported scopes, select pack-defined factory fittings, browse creative tabs by pack or use JEI/REI for compatible guns, ammo and attachments.
- Store rounds in tiered ammo storage or preview items on dyeable pegboards and connected, lockable cases. Hold a gun and use the interaction key (default **K**) to place it on the board or take matching ammo from storage.
- Under **Esc → TaCZ: View settings**, move the first-person gun and choose a static or expanding HUD, a color, shape or PNG. Settings are local to the launcher account; a gun overrides its category. HUD and position share codes do different jobs.
- Try pack-defined sights (UH-1 range, XM157 marker, XL50 thermal with occlusion), flash and smoke, world tracers and animation particles. Experimental scope PIP remains optional and off by default. Reimagined r5.9.3 has specific flash, hand exposure and SVD shadow checks, not a blanket shader certification.
- Three independent client Render options, all **off by default**: `MuzzleSurfaceLight` briefly lights nearby walls and ground ahead and to the sides; `ExplosionSurfaceLight` lights surfaces at the real detonation; `LegacyMuzzleLight` estimates gun/arm exposure for eligible old displays. Nearby armor stands, worn armor, non-glowing displays and dropped items can catch the flash. A case’s contents retain their existing full brightness while its backing can light up. No light blocks, gameplay change or added laser impact dot; the stock beam is unchanged.
- Actual drops with no usable authored LOD can use their slot icon from 8 blocks (`DroppedGunSpriteDistance`: `0` any distance, `-1` disabled). No icon means 3D, and held/displayed guns don't switch. Bedrock models also skip faces the author omitted, not valid faces with a zero-size UV.
- Rebind keyboard/mouse actions, unload supported guns, and use pack- or server-defined movement, mob anger, prone, airborne spread, team/entity and block-hit rules. Optional PAL and Controllable were tested separately. Gun packs can use version overlays and a check-then-export converter, without rewriting the input pack. Admin tools can generate a test pegboard wall of matching or different guns. Re-exporting updated built-in pack resources backs up the previous folder.

The mod now compares as `1.2.0`; this does **not** certify every 1.2.0 pack, port an old binary dependency or update the three other game-version files. Use matching client/server builds; back up your world before testing.
