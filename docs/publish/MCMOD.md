## ⚠️ MC 百科与两大站**本质不同**（先读这段）

1. **MC 百科是 Wiki 型资料站，词条是社区共同维护的**，不是你的个人页面。
   提交后由编辑审核，其他编辑也可能修改内容。因此文案必须**客观、中立、
   去营销化**。
2. **通常不直接托管 jar**，而是引导到 CurseForge / Modrinth 下载。
   → **建议先发那两站拿到下载链接，再来建词条。**
3. **收录规则第 6 条**：「未发布过任何可运行版本的Mod」不收录。
   → 必须**先有可下载的正式构建**再提交。
4. **收录规则第 5 条**：「涉及侵权、剽窃实锤的Mod」不收录。
   → 必须明确标注原作者与 GPL-3.0 授权（下面文案已覆盖）。
5. **收录规则第 11 条**：禁止「恶意占用已存在的MODID」。
   → 我们的 modid 仍是 `tacz`，这是**移植的必然要求**（否则枪包依赖全失效），
   **需在提交备注里主动说明**，避免被误判。下面已附备注模板。

## ③ 模组简介（亦适用于原词条的「移植版本」段）

《永恒枪械工坊：零》的非官方 Fabric 移植，基于 TACZ Dev Team 的原作与 Sh1roCu 的 Fabric 移植，沿用模组 ID `tacz`。各游戏版本独立构建。26.3 的 `1.2.0+fabric.26.3.R1` 开发构建移入了上游 1.2.0-hotfix 的部分功能，包含分级弹药库、陈列挂板与按账号保存的持枪位置和准星。已发布的 26.3 `1.1.8+fabric.26.3.R1-hotfix3` 文件早于这些变化。本项目与原作团队无隶属关系。

## ④ 详细介绍（资料底稿）

**维护状态（2026-11-27）。** 项目已从积极维护转为不定时更新，所有版本均无固定更新周期。Minecraft **26.1.2 与 26.2 已封存**，现有源码和发布文件保留供查阅，不再安排后续更新或修复。维护范围仅保留 **1.21.11 与最新版本线**，目前本项目最新适配线为 **26.3**；尚未适配的 Minecraft 版本不计入已支持范围。维护者不承诺响应、修复或新版本适配时间，并欢迎有意接手维护的人自行 fork、独立维护；代码及资源的原有许可证与署名要求保持不变。

**安装与版本。** 本移植为 Fabric 模组，客户端与服务端须使用相应游戏版本的文件，前置为 Fabric API 与 Forge Config API Port。26.3、26.2、26.1.2 使用 Java 25，1.21.11 使用 Java 21。26.3 开发版需要 Fabric Loader 0.19.5+ 和 Forge Config API Port 26.3.0+。下述新增内容的范围为 **26.3 开发版，含 #124 测试构建**，不作为站内已发布版本标签。

| 内容 | 26.3 开发构建中的行为 |
|---|---|
| 默认内容和改装 | 默认包索引含 70 把枪、25 种弹药、126 个配件条目（含内置件），另有 5 个转接座。包括 QR-24、M1897、M1866、PKM、SVD、MCX Spear LT 和 .300 BLK 等。原厂虚拟件与背包实物分开结算，部分瞄具须先装兼容转接座。创造栏可按内容包、武器类别浏览。 |
| 合成与查询 | 枪械制造台本身在原版 3×3 工作台合成，取得铁块可解锁配方书条目；枪械、配件、弹药各有专用制作台。JEI 或 REI 可双向查询适配关系。枪包晚到时 REI 保留服务端普通合成；多包同名工作台过滤器合并，只有黑名单不会令客机列表全空，明确禁用的配方仍不显示。持物筛选无结果时可取消筛选。 |
| 储存与陈列 | 弹药库分铁、金、钻石三档，可按弹种存取，升级时保留库存；持对应枪按持械交互键可取匹配弹药。挂板可染色、接角，展示柜可连片上锁。空槽提供预览，确认后放入一件；可旋转或取下展品。 |
| 视角与界面 | 持枪从 Esc 菜单进入「TaCZ 持枪与准星」。第一人称位置与腰射准星按本机启动器账号保存；单枪规则覆盖类别规则，类别覆盖账号默认。可调形状／颜色、设动态开合、用 PNG 或分享码。开镜分划、服务器弹道不随之改变。 |
| 瞄具与粒子 | UH-1 可显示测距文字，XM157 有镜内标记，XL50 显示未被墙体遮挡的合格热源。经典变焦与实验性画中画为不同路径，后者默认关闭。枪包可控制枪焰大小、烟量、曳光、方块命中特效、动画粒子；焰与烟可分别显示。Reimagined 指定配置下已验证枪焰颜色、手部曝光与 SVD 阴影。 |
| 可选近场补光 | 客户端渲染页的「枪口近场散射」作用于枪口前方及两侧的墙地，「爆炸近场散射」从实际爆点照亮附近表面。后续 26.3 开发构建也处理附近的盔甲架、装备、普通展品和架体；展示柜内物品仍保持全亮。「估算旧枪包击发曝光」另管适用旧枪的枪与手。三项默认关闭，不改变世界光照或致盲；保留原有镭射光束，不另画命中点。 |
| 远处掉落物 | 无可用低模且有槽位贴图的枪，默认从 8 格起以图标显示掉落物；`DroppedGunSpriteDistance` 为 `0` 时含近处，为 `-1` 时禁用。没有图标仍画 3D。不改变拾取、手持或陈列。 |
| 控制与玩法 | 默认 K 持枪交互；瞄准、改装等动作可重绑键鼠；支持的枪用 Alt + 换弹键或独立按键卸弹。换弹退出瞄准、背包散热、射手位移与枪声反馈依枪包及服务端规则而定。服务端可控制空手趴下、空中散布、队友穿过、实体过滤及可打碎方块。Controllable 手柄与 PAL 第三人称动画属于可选集成。 |

**枪包。** 第三方 ZIP 或文件夹从 `.minecraft/tacz/` 加载，`gunpack.meta.json` 位于包根。`tacz_backup/` 不用于正常加载。26.3 可按游戏版本选覆盖层；旧包可先检查并另行导出，不能转换的项目需另行处理。`dependencies.tacz` 按核心版本比较，精确锁定 `1.1.8` 的包不匹配 `1.2.0`。本移植不提供 TacZ:Arcana 加密资源的读取能力。查看器作弊拿到无模型、名称为 `item.tacz.*` 的物品时，与从创造栏取得的同物品对照：缺少枪包 ID 的物品栈与整个枪包缺材质不是同一问题。

**范围与许可。** 内置 VellEagle 的 TML 高模渲染与 LesRaisins 的部分 LRTactical 框架，不含后者完整美术或 `flash_shield`。本移植代码为 GPL-3.0；默认枪包的模型、贴图、动画与声音为 TACZ Dev Team 的 CC BY-NC-ND 4.0 资源，不因截图或代码分发而改用 GPL。随包 MAE 为 MIT，26.3 开发版移入的 SimpleBedrockModel 粒子／Molang 代码为 LGPL-3.0。移植问题由本仓库受理。
