# 弹簧疲劳数值验证

## 1. 供弹具弹簧疲劳（FeedDeviceData.springFatigue）

### 当前增量
- BoxMagazineData: +0.001 / 次 stripNextRound
- DrumMagazineData: +0.001 / 次 stripNextRound + 0.005 windingTension

### 疲劳阈值与可靠性影响

| springFatigue | BoxMagazine.getSpringReliabilityModifier() | DrumMagazine.getSpringReliabilityModifier() |
|--------------|-------------------------------------------|---------------------------------------------|
| 0.0 - 0.3    | 1.0 (无影响)                               | 1.0 (无影响)                                 |
| 0.3 - 0.6    | 0.9 (-10%)                                 | 0.85 (-15%)                                  |
| 0.6 - 0.8    | 0.7 (-30%)                                 | 0.6 (-40%)                                   |
| 0.8 - 1.0    | 0.4 (-60%)                                 | 0.3 (-70%)                                   |

### 达到阈值所需射击次数

| 阈值 | BoxMagazine (+0.001/次) | DrumMagazine (+0.001/次) |
|------|------------------------|--------------------------|
| 0.3 (轻微影响) | 300 发 | 300 发 |
| 0.6 (明显影响) | 600 发 | 600 发 |
| 0.8 (严重) | 800 发 | 800 发 |
| 1.0 (完全疲劳) | 1000 发 | 1000 发 |

### 结论
- 1000 发后弹簧完全疲劳，供弹可靠性下降 60%（盒式弹匣）或 70%（弹鼓）
- 300 发后出现轻微影响，对应现实中的"需要更换弹簧"时机
- **数值合理**：一支步枪在战斗中可能发射数百发，弹簧疲劳在合理范围内

### DrumMagazine 发条张力
- windingTension: +0.005/次消耗，从 1.0 开始
- 0.7 以下：可靠性 0.85
- 0.4 以下：可靠性 0.6
- 0.2 以下：可靠性 0.3
- 达到 0.7 阈值需要 60 发 (0.3/0.005)
- 达到 0.4 阈值需要 120 发 (0.6/0.005)
- **数值合理**：弹鼓需要频繁上发条，60发后开始出现供弹问题是合理的

## 2. 枪械弹匣弹簧耐久（GunWearData.magazineSpringDurability）

### 当前值
- 默认最大: 2000
- 每次供弹循环消耗: 1
- 可靠性权重: 0.15

### 达到阈值所需射击次数

| 磨损比例 | 射击次数 | 对可靠性贡献 |
|---------|---------|-------------|
| 30% | 600 发 | -0.045 (0.15 × 0.30) |
| 50% | 1000 发 | -0.075 |
| 70% | 1400 发 | -0.105 |
| 90% | 1800 发 | -0.135 |

### 结论
- **与 FeedDeviceData.springFatigue 是两套独立系统**：
  - springFatigue 是**供弹具物品**的磨损（弹匣/弹鼓作为独立物品）
  - magazineSpringDurability 是**枪械自带弹簧**的磨损（固定弹仓的弹簧）
- 两者通过加权公式统一：recoilSpringWear(0.20) + magazineSpringWear(0.15) = 0.35
- **不存在双重计算**：springFatigue 影响的是 FeedDeviceData 的 stripNextRound 成功率，
  magazineSpringWear 影响的是 GunWearData 的 overallReliability

## 3. 复进簧耐久与弹簧疲劳的统一

### 统一公式
```
overall_reliability = 1.0 - (
    barrelWear * 0.10
    + receiverWear * 0.20
    + boltWear * 0.30
    + recoilSpringWear * 0.20     ← 复进簧（枪机回位弹簧）
    + magazineSpringWear * 0.15   ← 弹匣弹簧（供弹弹簧）
    + triggerGroupWear * 0.05
)
```

### 两套弹簧系统的职责划分

| 系统 | 物理对应 | 数据位置 | 影响环节 |
|------|---------|---------|---------|
| recoilSpringWear | 复进簧（枪机回位） | GunWearData | 整体可靠性 (0.20 权重) |
| magazineSpringWear | 弹匣弹簧（供弹） | GunWearData | 整体可靠性 (0.15 权重) |
| springFatigue | 供弹具弹簧（可拆卸弹匣） | FeedDeviceData | stripNextRound 成功率 |

三套弹簧系统分别对应不同的物理弹簧，在加权公式中各自独立贡献，**无重叠**。
