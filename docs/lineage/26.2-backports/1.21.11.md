# 接收单：Fabric 1.21.11

**OPEN。** 接收基线 [`aac343a`（R3-hotfix4）](https://github.com/q14433686-arch/TaCZ_Refabricated_Unofficial/tree/aac343af891858589eaea69bbefc413c0f2b1977)。按[公共批次](README.md)迁移。建议先用一个小的非渲染批次从源码走通到**发行 JAR 实际进服**，再接其余功能；这条线特有的失败常常发生在编译之后。

| 边界 | 具体做法 |
|---|---|
| Java 与映射 | 保留 **Java 21**、`net.fabricmc.fabric-loom-remap` `1.17.19`、official Mojang mappings、Loader `0.19.3`、Fabric API `0.141.6+1.21.11`、FCAP `21.11.1`。见[目标 Gradle](https://github.com/q14433686-arch/TaCZ_Refabricated_Unofficial/blob/aac343af891858589eaea69bbefc413c0f2b1977/build.gradle)。保留 `modImplementation`、access widener、Mixin AP 和 `tacz.refmap.json`。移植每个注入点先对本版 owner、描述符和 handler 参数；优先稳定具名入口，确需命中合成方法时查目标 intermediary `method_…`，不照抄 `lambda$…$N`。 |
| 包与网络 | 保留历史 `resources/tacz-26.1.2-source-and-resource-bundle.jar`，**名字不是目标游戏版本**。本线 `overriddenBySource` 只排除有同路径源码的旧件；退役配方仍要显式排除。用 `[1.21.11]`、本版 DFU/registry codec 生成资源，核对 remap 后 JAR 的有效索引、组件与备份，不拷 26.2 的 pack metadata。版本谓词、分片、虚拟配件、HUD 的纯逻辑可先移；将读写栈、菜单、真实连接的重载/断线回调接到本版。 |
| 查看器与可选兼容 | 基线 JEI `27.23.0.71` 已有客户端生命周期 listener，不要退回伪造服务器 recipe-update；REI `21.11.816` 的插件重载另按该版核对。先分装验证普通配方不消失、专用台按 `BlockId` 与包过滤，再独立查[给物路径](README.md#rei)。PAL 用目标的 `1.1.9`，不是 26.2 的 `1.2.5`；手柄也用本版构件。先测缺席时能启动，再测实际安装时的第三人称/输入。 |
| 光影与手部 | 沿用 `ScopeDepthCopyState` + `ScopeFinalOverlayState` 的深度孔径和终局绘制，重投影与 `ScopePipRerender` 分开。目标 `LevelRenderer.renderLevel` 接收视图、投影矩阵；不要反抄 26.1.2 的共享状态重提取或 26.2 的投影上传 mixin。以 **1.21.11** 的 shader/include 为底接入材质、镜孔方向、真实分划和热像深度匹配。`sample_lightmap.glsl` 就是曾在旧版缺失、能编译却导致资源重载黑屏的例子。 |

**在干净的目标版缓存和 JDK 21 下执行**（目标仓根目录；shader 检查器会从 `~/.gradle` 选择 merged JAR，先确认选中 1.21.11）：

```bash
./gradlew help --no-daemon
python3 docs/verify_mixin_targets.py
python3 docs/verify_shader_imports.py
python3 scripts/verify_263_sync_baseline.py
./gradlew clean build remapJar
jar tf "${PRODUCT_JAR:?指定 remap 后的发行 JAR}" | grep -Fx tacz.refmap.json
sha256sum "$PRODUCT_JAR"
```

把该文件（不是 dev/sources JAR）装入两个独立的 Java 21 进程。先查生产环境 Mixin 实际生效、没有缺失 refmap 或 shader include，再重进旧存档、用服务器专有包做真正 `/reload` 和重连。按[光影对照](README.md#optics)在本版 Iris/Sodium 上测经典/PIP 和退出 ADS 后深度恢复。`runClient` 成功不代表 remap 成品可用；没有目标版原帧的组合保持未测。
