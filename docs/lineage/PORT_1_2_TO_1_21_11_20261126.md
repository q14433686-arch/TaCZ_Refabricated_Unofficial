## 第一批的本线适配

- 使用 `PayloadTypeRegistry.playS2C()`，不照抄 26.x 的 `clientboundPlay()`。
- 使用 `ClientCommandManager.literal` 和本线 `ChatComponent#addMessage`；兼容提示只改本地偏好，服务器不能替玩家 dismiss。
- 每个 repository source 捕获自己的 `PackType`，避免集成服客户端与服务端覆盖同一枚举字段。
- `openPrimary` 仅负责元数据，`openFull` 每次新开目录/ZIP 图层，元数据探测关闭不会提前关闭游戏实际使用的 ZIP。
- 图层内沿用本线 `LegacyGunPackRecipeMigrator`，保留旧版工作台的普通合成别名与 `BlockId`；**没有搬入 26.x GunPackLangCompat**，不改变 1.21.11 原生语言资源兜底。
- 分片只有完整解压且解码后才安装缓存/重建索引/请求查看器刷新。进入新连接先清理旧分片；排队的缓存安装和远端提示均核对当前 Connection，迟到的旧服任务不能污染新连接。没有为此新增混淆敏感的客户端 teardown mixin。
- 转换目标固定为 `1.21.11` / `compat_1_21_11`，DFU 目标 DataVersion 来自当前游戏；配方、loot、advancement、Ingredient 使用目标运行时 codec 验证。保留旧 `conditions/functions` schema，不输出 26.3 loot schema。
- 转换使用 `check` / 独立输出目录 `export`；保留输入包和脚本，不修改玩法依赖。无法等价转换的配方置为 partial/跳过，并在目标 overlay 屏蔽其旧别名；不能把 partial 当成完整兼容。
- 配方注册表结果改为复用 Gson 的延迟解析和源 JSON 回写，而不是丢弃 CUSTOM、NBT 与组件的旧 `ResultSpec`；Ingredient 编码继续使用本线 RegistryOps。

### 命令

```text
/tacz convert universal "包目录或ZIP名" check
/tacz convert universal "包目录或ZIP名" export
/tacz convert universal all check
/tacz convert universal all export
```

源包必须是实例 `tacz/` 的直接子目录/ZIP；输出到 `tacz-converted/`，不会自动安装。使用副本、查看 JSON 报告，再把导出包装入目标实例，进行真正 `/reload`、合成与旧档重开检查。
