| 保留目标配置 | 核对值 |
|---|---|
| 构建 | MC 1.21.11，**Java 21**，Loader 0.19.3，`fabric-loom-remap` 1.17.19、official Mojang mappings |
| 硬依赖 | Fabric API `0.141.6+1.21.11`、Forge Config API Port `21.11.1` |
| 查看器编译 pin | JEI `27.23.0.71`、REI `21.11.816` |

1. **先保住成品能启动。** 共用的配置数值、HUD 档案、分享码、包顺序与分片逻辑先在 Java 21 编译；请求/响应 codec、菜单、配方书奖励和实体存档按本版 registry 检查。维持 `modImplementation`/`modCompileOnly`、access widener、Mixin AP 和 `tacz.refmap.json`，不因开发环境能进世界就关闭 remap。新增 mixin 核对真实方法描述符；优先具名入口，必须定位合成目标时查本版 intermediary `method_…`，不照搬 `lambda$…$N`。
2. **资源和客户端都要验成品。** 本线仍从名为 `tacz-26.1.2-source-and-resource-bundle.jar` 的历史包兜底；[`overriddenBySource`](https://github.com/q14433686-arch/TaCZ_Refabricated_Unofficial/blob/aac343af891858589eaea69bbefc413c0f2b1977/build.gradle#L263-L302) 显式排除同路径旧件。对退役资源另作排除；检查 GLSL `#moj_import` 指向 **1.21.11** 自带的 include，不搬 26.3 的 `#include`/OIT/shader 二进制。复用 `ScopeDepthCopyState` 和本线 `ScopePipRerender`；分别测默认镜、可选 PIP、Iris 和关闭光影后世界深度恢复。
3. **分开试插件。** JEI 基线已有生命周期 listener；REI `.816` 的全部插件重载与 `.823` 的实现不能视为同一 API。按本版展示所有权实现增量刷新；跑真服务器配方先到、枪包后到、再次 `/reload` 三步。再测两启动器账号下的 HUD、持枪偏移、热插拔内容包后按枪 ID 的规则仍生效。保留目标线已有的兼容层，不把旧版依赖塞进 26.3 或反向使用。

在**只缓存目标游戏的环境**运行下列命令（shader 校验器会从 Loom 缓存选择合并 jar）：

```sh
./gradlew help --no-daemon
python3 docs/verify_mixin_targets.py
python3 docs/verify_shader_imports.py
python3 scripts/verify_263_sync_baseline.py
./gradlew clean build remapJar
```

这些检查不能代替运行。把 **remap 后的发行 JAR**（非 dev/sources）装入干净的 Java 21 Fabric 客户端与专服，而非只测 Loom `runClient`。记录启动及资源重载无 refmap/注入/shader 错误、实际配方结果和同机位镜内对照；任何一个只在开发环境通过的项都不要标 DONE。
