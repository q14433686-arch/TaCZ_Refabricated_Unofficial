# 26.3 → 26.1.2 修改项核对与回移记录

- **核对基线**：本工作分支 `1ec4429`（26.1.2；`minecraft_version=26.1.2`，JEI `29.5.0.26`，REI `26.1.819`）。
- **对照对象**：远端 `26.3` 当前头 `e1f57a2`，不把它当成本线可直接合并的基线。
- **原则**：逐项确认问题是否与本线共同代码/API 有关；只移植能在 26.1.2 API 上成立的独立修复，不整支合并、不覆盖本线已有回移与本线特有实现。

## 已同步

### 弹孔朝向与贴面偏移

从 26.3 当前树同步弹孔朝向修复至 `BulletHoleParticle.extract`：

- `Direction#getRotation()` 的局部 +Y 法线约定与 vanilla 粒子四边形局部 +Z 法线不一致；增加 `Rx(-90°) * Rz(180°)` 基变换，避免不同命中面上的弹孔四边形朝向错误，同时保持原 UV 角序。
- 原先局部 Y 方向的防 z-fighting 偏移改为沿命中面法线偏移。
- 使用插值后的粒子世界坐标减相机位置，显式构造相机相对位置，再调用六参数 `extractRotatedQuad` 重载；颜色/透明度仍经父类字段传递并在 `finally` 中还原。

新增离线验证 `scripts/verify_bullet_hole_orientation.py`：覆盖六个命中面法线、四角/UV 几何、相机平移与 partial tick，以及 Java 源码接线。该测试通过，但只是四元数模型和静态源码检查，不代替客户端实机测试。
