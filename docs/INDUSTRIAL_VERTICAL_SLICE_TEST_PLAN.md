# 工业制造纵切：材料、弹药与三平台装配测试

> 对应实现：Create Fly 工业链 Phase 2/3（AK、AR、Glock 首批平台）

## 前置

- 服务端配置：`IndustryProfile = "CREATE_FLY"`；
- Create Fly 必须在客户端与服务端加载；
- `PhysicalMagazines = true` 可同时测试实体弹匣；
- 本测试只覆盖 TACZ 内置 `tacz` 默认包，不改变任何第三方枪包配方。

## 1. 配方查看器桥接

- JEI 应继续显示 Create Fly 原生完整树；
- REI 应新增 TACZ 的工业研磨、工业粉碎、加热/炽热鼓风炉搅拌、机械冲压、压实装配类别；
- 点击碳粉、硫粉、朱砂粉、钢板、零件、弹药或最终 AK/M4/Glock 时，应能沿输入/输出查到完整 TACZ 工艺链；
- REI 显示来自服务器同步的 `recipe/create/` 工艺投影，专用服务器也应可用。

## 2. Create Fly 基础材料链

按顺序在 REI/JEI 或 Create Fly 配方查看器中确认下列配方存在：

```text
煤 / 木炭 --研磨--> 碳粉
硫黄 / 强效硫黄 --粉碎--> 硫粉
朱砂 --研磨--> 朱砂粉
铁锭 + 碳粉 + 方解石 --加热搅拌--> 生铁
生铁 + 碳粉 + 石英 --炽热搅拌--> 高碳钢
高碳钢锭 --冲压--> 高碳钢板
碳粉 + 硫粉 + 红石 --加热搅拌--> 工业推进药
黄铜锭 --冲压--> 弹壳坯
黄铜粒 + 朱砂粉 + 硫粉 + 红石 --压实--> 底火组件
```

其中加热 Basin + Mechanical Mixer + Blaze Burner 是当前“鼓风炉单元”。它不是额外复制一台 TACZ 机器，而是明确要求 Create Fly 的热源、动力和加工物流。

## 3. 批量弹药

确认 `create:compacting` 产出带正确 `AmmoId` 的 TACZ 弹药：

- 9 mm：32 发；
- 5.56×45：24 发；
- 7.62×39：20 发；
- 12G：12 发。

输入应来自带对应 `CartridgeCaliber` 的弹壳坯、带对应口径和 `ProjectileType` 的弹头坯、底火组件和工业推进药。产物必须能够：

1. 正确显示 TACZ 弹药名称与模型；
2. 正常装入实体弹匣；
3. 被对应枪械实际射击消耗。

在 `CREATE_FLY` 档，枪械工作台中原有的 9 mm、5.56×45、7.62×39、12G 默认散装弹药配方应不再出现，避免用铜锭/火药绕过工业链。

## 4. 可复用模板与零件

Create Fly 压实配方应能制作：

- AK、AR、Glock 三类装配模板；
- 对应机匣、枪机组/套筒、枪管、击发组、复进组件。

模板 Tooltip 应标注“工装（不消耗）”。模板和组件都使用 NBT 身份；例如 AK 机匣不能代替 AR 机匣。

## 5. 最终枪械装配

在默认枪械工作台中测试：

| 成品 | 必需平台件 |
|---|---|
| AK-47 | AK 模板、机匣、枪机组、7.62 枪管、击发组、复进组件、木板 |
| M4A1 | AR 模板、机匣组、枪机组、5.56 枪管、击发组、缓冲复进组件、木板/皮革 |
| Glock 17 | Glock 模板、枪身、套筒/枪机、9 mm 枪管、击发组、复进簧、皮革 |

预期：

- 制作成功后五种平台组件会消耗；
- 模板保留在背包中；
- 不同平台组件不能互相替换；
- 成枪不免费附带散装子弹或弹匣，需另外生产并装填实体弹匣。

## 6. LEGACY 回退

把 `IndustryProfile` 改为 `LEGACY` 并重启/重载后确认：

- 原默认枪械工作台配方重新出现；
- Create Fly 工业终端配方不再接管 AK/M4/Glock 与四种弹药的 TACZ 工作台路径；
- 已存在的工业组件、模板、实体弹匣不会损坏存档。
