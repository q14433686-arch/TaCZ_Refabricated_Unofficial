# 工业制造纵切：材料、弹药与三平台装配测试

> 对应实现：Create Fly 工业链 Phase 2/3（AK、AR、Glock 首批平台）

## 前置

- 服务端配置：`IndustryProfile = "CREATE_FLY"`；
- Create Fly 必须在客户端与服务端加载；
- `PhysicalMagazines = true` 可同时测试实体弹匣；
- 本测试只覆盖 TACZ 内置 `tacz` 默认包，不改变任何第三方枪包配方。

### 0.5 参考档案与第三方接入审计

1. 资源重载后以管理员执行 `/tacz industry audit`：默认包应报告已校验的参考档案和零个未解析默认枪结果；
2. 执行 `/tacz industry reference tacz:ak47`、`/tacz industry reference tacz:m870`、`/tacz industry reference tacz:m249`、`/tacz industry reference tacz:rpg7`：依次确认动作、供弹设备、运行时机制、容量、弹药类别和 tier；M870 必须是 `tube`，M249 必须是 `belt`，RPG-7 必须是 `single_shot`，不能都显示成 detachable magazine；
3. 安装第三方包后，审计只能把有有效 Index/Data 的枪标记为 `surveyed` 候选；没有 `industry/reference` / `industry/gun_feed` 的第三方枪必须保持 `legacy` 供弹，不能因为其旧 `reload.type = magazine` 被自动变为实体弹匣；
4. 对输出 ID 错误的第三方工作台配方，先观察审计的 `unresolved` 行；只有添加带 `expected_ammo` / `expected_capacity` 的显式 `industry/id_aliases` 条目后才允许其进入自动工业门槛。不要用文件名猜测直接修复。
5. 对一把已审计但没有 `industry/assembly` 高保真声明的第三方枪：先在 Basin 制作测绘档案包、在机械合成器制作测绘夹具；在 Gunsmith Table「工业档案与平台套件」页（`tacz:industry_platform`）委托其测绘 master dossier，再转印生产工装；用五种中性结构毛坯、生产工装和夹具制作“测绘平台结构套件”。最终成枪配方应在独立的「工业总装」页（`tacz:industry_assembly`）保留原材料表，并额外要求该 kit、生产工装和夹具；默认高保真枪不得被改成这条 GUI fallback。
6. 对已审计的第三方普通 ammo：「测绘弹药工艺」页（`tacz:industry_cartridge`）应出现 `[namespace:ammo]` 测绘量规、弹壳和弹头操作；量规委托消耗原 ammo 材料表和中性弹药量规毛坯，后续弹壳/弹头必须带精确测绘 AmmoId/口径标签，最终只在四槽弹药装配机完成。射击后应产生标准材质族的已击发对应口径弹壳，并可通过量规/夹具操作整形；fuel/inventory/未解析 ammo 不得错误进入该流程。同一 AmmoId 若被多个枪包旧工作台配方重复输出（包括第三方兼容包使用 `tacz:` 命名空间的额外 AmmoIndex），`CREATE_FLY` 下所有铜锭/火药旧捷径都必须消失，只留下同一条测绘量规 → 四槽装配链。
7. 安装 Cold War 后，对 `rainforest:56`：「实体供弹器件」页（`tacz:industry_feed`）应出现 `[rainforest:56]` 桥夹制造委托；空桥夹可装入 5 发 7.62×39。将枪内设为 7/10 后换弹，预期只转入 3 发、桥夹仍是同一件物品且剩 2/5；不能因桥夹余弹小于枪内当前 7 发而拒绝。把这只半满桥夹与同口径散装弹右键叠放应可补装，或对空槽右键取出剩余 2 发。桥夹被中途移动/替换时必须整次装填失败，不能改扣其他来源；桥夹即使真的转空也必须作为 `0/5` 的同一 ItemStack 保留。该枪包当前没有真实逐发循环动画，因此移除桥夹、保留散装 7.62×39 时**不得**伪造成“每按一次 R 加一发”；其 `loose_reload_mode=none` 应拒绝该无动画路径。创造模式/无限装填时则不要求背包有桥夹：一次 R 必须按原批量动画虚拟转入至多 5 发且不生成/消耗假桥夹，连续两次可完成空枪的 10 发装填。
8. 对默认 M870、M1014、SPAS-12：各自只按**一次** R，原包逐发循环动画应持续到枪满、散装弹耗尽或玩家打断。每个已播放 feed 点应即时减少一发散装弹并增加一发内仓/枪膛；打断后，已完成的几发必须保留，未播放的余弹仍留在背包，不能在收尾时一次性补满。
9. 安装 GunpowderRevolution 后，对 `hamster:mosin91` / `hamster:mosin9130`、`gew98`、`m1903`、`type99`：空仓、无瞄具、缺满 5 发且背包有同族满 5 发桥夹时，必须走原包桥夹批量动画并从该桥夹扣 5 发；桥夹显示为 `0/5` 但仍留在背包。移走桥夹但保留散装 `hamster:long_ammo` 后，同一把枪必须走原包逐发循环，一次 R 连续逐发装填；不能再播放桥夹动画。安装瞄具、只缺 1–4 发、或桥夹本身不足 5 发时也不得伪造满桥夹动画；若有散装弹则走逐发路线，若没有散装弹则拒绝换弹并保留半满桥夹。
10. 对默认 `tacz:kar98`：空仓、无瞄具、背包有完整 5 发 Kar98k 桥夹时应走原包桥夹动画，实际消耗 5 发（1 发上膛、4 发内仓）并留下空桥夹；没有完整桥夹时应强制原包真实 `reload_loop` 逐发路线，而不是播放桥夹动画后从散装弹批量扣除。
11. 对两种已审计 M1 分别回归：`hamster:m1garand` 必须使用装满 `hamster:long_ammo` 的 8 发 M1 漏夹，`ww:m1g` 必须使用装满 `tacz:30_06` 的另一种 8 发 M1 漏夹；两者不能混用。R 装入后枪 NBT 必须保存 `InstalledEnBlocClip`，而不是普通 `InstalledMagazine`，也不得写入桥夹/转轮专用的 `InternalFeedAmmoCount`；每发实际射击扣除漏夹余弹；最后一发真正离开供弹系统后，空漏夹必须从枪手右前方以真实 `ItemEntity` 弹出（短暂不可拾取，随后可由玩家/漏斗收集），而不是静默返还背包或等到切枪动画才处理。创造模式无实体漏夹时，R 仍必须完成一次不消耗来源的 8 发装入；潜行 + R 应能人工退出尚有余弹的漏夹；生存模式没有物理漏夹时不得从散装弹伪造 M1 装夹。
12. 对 `hamster:webley`：完整 6 发实体快装器应让原 `reload_loader` 动画运行，先按上游语义清空转轮旧弹再装满 6 发，空快装器保留在背包；移走完整快装器但保留散装 `hamster:medium_ammo` 时应走原逐发循环；半满快装器不能冒充完整 loader 动画。
13. 枪械熟练度：用一把带 `GunExperienceToken` 的枪确认命中与击杀；同一把枪应累加 `GunLevelExp`，0–10 Tooltip 进度与升级消息应更新。射击后换到另一把相同 GunId 的枪再命中，经验必须仍归给发射时绑定 token 的原枪。达到较高等级后，Tooltip 必须明确显示当前 ADS、真实投射物散布和本地后坐操控收益；服务器实际弹道散布与服务器/客户端 ADS 进度要同步变小，不能只改 Tooltip。熟练度仍不得增加直接伤害、护甲穿透、维修折扣或绕过维护故障。

## 1. 配方查看器桥接

- JEI 应继续显示 Create Fly 原生完整树；
- REI 应新增 TACZ 的工业研磨、工业粉碎、加热/炽热鼓风炉搅拌、机械冲压、**工作盆压实**、部署器成型、**真实多槽机械合成器**和**顺序枪械装配**类别；
- 点击碳粉、硫粉、朱砂粉、钢板、零件、弹药或最终 AK/M4/Glock 时，应能沿输入/输出查到完整 TACZ 工艺链；顺序装配页必须标明置物台/传送带只有一个流动工件，并显示 `D→P→…` 实际工位图例（D=部署器、P=动力冲压机、F=液体喷嘴），不能再只有模糊的机械手图标；
- REI 显示来自服务器同步的 `recipe/create/` 工艺投影，专用服务器也应可用；
- 重载日志中不得出现 `Ambiguous Create compacting recipes`，也不得出现 `ingredients type is too many, expected range [0-9]`。

## 2. Create Fly 基础材料链

按顺序在 REI/JEI 或 Create Fly 配方查看器中确认下列配方存在：

```text
煤 / 木炭 --研磨--> 碳粉（12 / 8）
硫黄 / 强效硫黄 --粉碎--> 硫粉（16 / 32）
朱砂 --粉碎--> 朱砂粉（16）
铁锭 + 碳粉 + 方解石 --加热搅拌--> 生铁
生铁 + 碳粉 + 石英 --炽热搅拌--> 高碳钢
高碳钢锭 --冲压--> 高碳钢板
碳粉 + 硫粉 + 红石 --加热搅拌--> 工业推进药（16）
黄铜锭 --冲压--> 弹壳坯
黄铜粒 + 朱砂粉 + 硫粉 + 红石 --压实--> 底火组件（8）
```

其中加热 Basin + Mechanical Mixer + Blaze Burner 是当前“鼓风炉单元”。它不是额外复制一台 TACZ 机器，而是明确要求 Create Fly 的热源、动力和加工物流。

## 3. 专用弹药装配机

确认弹药装配机 GUI 可按独立槽位产出带正确 `AmmoId` 的 TACZ 弹药。默认枪包全部 24 种散装弹必须都能查到一条 `industry/cartridge_assembly` 定义并完成一次装配：

- 手枪/PD：9 mm、.22 WMR、.45 ACP、4.6×30、5.7×28、7.62×25、.357 Magnum、.50 AE；
- 步枪/机枪：5.45×39、5.56×45、5.8×42、6.8×51 Fury、7.62×39、7.62×54R、7.92×57、.308、.30-06、.338、.45-70、.50 BMG；
- 霰弹：12G；
- 爆炸弹药：40 mm HE、RPG-7 HEAT 火箭。

有对应默认枪的口径应先用“中性弹药基准量规毛坯 + 同口径样枪”得到一枚可复用口径基准量规，再由这同一枚量规分别校准弹壳/弹头模具；不得让完整枪直接重复产出两枚不同模具。无对应默认枪的 4.6×30、5.45×39、6.8×51 Fury、7.62×25、7.62×54R 应先在机械合成器制造各自的淬硬口径量规，再校准弹壳/弹头模具；不得出现使用错误枪械校准或同一 Basin 输入随机产出口径的路线。RPG-7 必须依次产出并可在背包/传送带上看到“火箭发动机壳体 → 火箭发动机总成（`IndustryPartKind=case`）”以及“战斗部弹体 → 装药战斗部 → 聚能破甲战斗部预制件 → 聚能破甲战斗部芯”；发动机壳体 `motor_housing` 不得直接塞进装弹机绕过 `finish_case_rpg_rocket`。40 mm 也必须有可见弹体和高爆装药弹体，不能把 TNT 藏在不可见临时态里；.50 BMG 壳/弹头成型应各走“初始毛坯 + 3 枚额外毛坯 + 对应模具”的单工件顺序线，不能与 9 mm 同样只消耗一枚毛坯。

先确认动力冲压机只会把黄铜锭/生铁压成中性弹壳毛坯/弹头毛坯；随后使用部署器持有对应口径、类型的冲压模具。部署器应保留模具，并把毛坯真正转换成带 `CartridgeCaliber` 的弹壳坯、带口径和 `ProjectileType` 的弹头坯。

逆向回归：一发完整散装弹 + 中性量规毛坯应消耗样本并得到完整口径量规；新/已击发弹壳只能得到弹壳尺寸量规并只能校准弹壳模；弹头芯只能得到弹头外形量规并只能校准弹头模。样枪和无默认枪 datum 仍可得到完整口径量规，不能被错误证据替代。

稳定档案回归：在默认枪械工作台「工业档案与平台套件」页（`tacz:industry_platform`）选择明确的档案委托，消耗同 tier 档案包与空白工装页、保留对应动作夹具，输出选定平台的 `master` 原始工艺档案；手持枪触发自动“按手中物品”过滤时，档案委托仍必须可见。随后该档案应能正常转印 production 模板。

在弹药装配机中分别放入：指定口径弹壳、指定口径/类型弹头、底火、工业推进药；点击“装配”。服务器必须只在四格同时匹配同一条 `industry/cartridge_assembly/*.json` 定义且**四格数量均达到该定义批量**时扣料，并输出整批对应弹药。默认回归至少核对：9 mm 消耗 24 壳/24 弹头/24 底火/2 推进药并输出 24；5.56×45 为 16/16/16/3→16；.50 BMG 为 4/4/4/8→4；40 mm 为 1/1/1/2→1。错误口径、错误类型、错误底火/推进药、数量不足或满成品槽都不得消耗任何输入。

自动化回归：从顶部或四个侧面用漏斗或 Create 物流送入上述材料，机器必须按物品身份路由到正确槽位；从底面只能抽取成品。给予红石信号后，进度条应在 40 tick 内完成一次装配；撤去信号、改坏输入或堵塞成品槽时进度必须归零且不扣料。产物必须能够：

1. 正确显示 TACZ 弹药名称与模型；
2. 正常装入实体弹匣；
3. 被对应枪械实际射击消耗。

在 `CREATE_FLY` 档，默认枪包全部 24 种散装弹药的旧枪械工作台配方都不应再出现，任何第三方包重复输出相同 AmmoId 的铜锭/火药旧条目也必须一并消失，避免靠另一份 recipe id 绕过专用弹药装配机工业链；`LEGACY` 档则应完整保留它们。

### 3.5 模板探索与村民采购

1. 升级一名武器匠至大师；其 26.2 数据驱动 level-5 商品池应保留原版交易，并随机出现 TACZ 工业模板商品。模板花费绿宝石和一本书，交易结果必须是带精确 `IndustryPlatform` 的 `tacz:gun_blueprint`，不是成枪；
2. 检查武器匠/工具匠村庄箱、废弃矿井、要塞、掠夺者前哨、林地府邸、古城和试炼密室稀有奖励箱：应有概率出现一张随机工业模板；
3. 用交易或箱子得到的模板直接校准模具并参与总装，必须与旧压实路线得到的同平台模板完全兼容；旧模板压实配方仍应存在，作为不探索/不交易时的后备路线。

## 4. 真实抛壳与弹壳回收

以已工业装配的弹药分别测试 Glock 17（9 mm）、M870（12G）、Kar98（7.92×57）、M320（40 mm）和 RPG-7：

1. 对 `eject_case: true` 的枪，每次真正消耗一发后，应从射手**右侧**产生一个可见、可拾取的原生掉落物（面北时向东、面南时向西），而不是只有客户端短暂动画；连发、双管和霰弹每发只产出**一枚**完整弹壳/弹壳壳体，不能按 pellet 数倍增；
2. 掉落物必须是 `tacz:cartridge_case`，带 `IndustryPartKind=spent_case`、精确 `CartridgeCaliber`、`CartridgeAmmoId` 和 `SpentCartridgeCase=true`；玩家和漏斗均可回收，连续射击的同口径壳可按原版规则堆叠/合并；
3. 将回收的壳送上部署器置物台，并让部署器持有**相同口径**的 `case_die`：应转成对应的未装填 `IndustryPartKind=case`。错误口径模具、弹头模具或没有模具都不得使它变成可装填弹壳；
4. 整形后的壳必须仍需通过弹药装配机补充一枚新弹头、一枚底火和一份推进药；不能把 `spent_case` 直接塞进装配机，也不能复制弹药；
5. RPG-7 发射火箭时不应产生可回收弹壳（`eject_case=false`）。创造模式未实际消耗弹药时也不应凭空刷出可回收壳。
6. 分别检查 9 mm、12G、40 mm 的成型弹壳、成型弹头、重新整形壳与掉落 spent case：其 `minecraft:max_stack_size` 必须与同 `AmmoId` 的最终散装弹一致（预期分别为 60、36、6），而不是统一旧值 16。旧存档的壳/弹头放入玩家背包后也应自动校正。

### 4.5 工业回收、弹匣袋与装弹器

1. 制造工业回收站；从顶部/侧面只允许送入一件枪、实体弹匣或模具，底面只能抽取回收产物。红石信号下应在 40 tick 完成一次有效回收；
2. 将一只**空**实体弹匣送入：应输出 `magazine_blank`；带余弹弹匣不得被消耗。将已配置 case/projectile/component die 或口径量规送入：应回收高碳钢板和黄铜粒；
3. 用工业终端新制造轻型手枪、普通步枪和重型机枪/反器材枪各一把，先安装附件或插入实体弹匣分别测试：回收站必须拒绝且不消耗枪。退匣并拆下附件后，内置供弹/枪膛中的弹应以散装弹安全输出；轻枪、普通长枪、重枪分别应按重量得到递增的 3–5 件结构毛坯、1–4 块钢板和 60% 外装材料。旧工作台枪、战利品枪或没有 `IndustryAssemblyPlatform` 的同 GunId 枪不得回收工业零件；
4. 弹匣袋与装弹器配方的金属件应为 Create 的 `create:copper_sheet`，不得再要求高碳钢板；
5. 手持弹匣袋，在背包中右击已配置实体弹匣：最多收纳四只，余弹数必须保留。右击空槽或手持袋在空中右击应取出完整同一只弹匣；
6. 在玩家背包/容器界面把已配置实体弹匣、桥夹或漏夹拿在光标上，按想要的顺序右击同 canonical calibre 的不同 AmmoId：每次右击应立即转入该来源可容纳的数量。手持装弹器右击载具应立即从背包中首个兼容散装弹堆转入，不得启动逐发后台计时；
7. 载具拿在光标上右击空槽时必须立即退出顶部连续且 AmmoId 相同的一段弹药到该槽；输出被占用或身份无效时，不得吞弹、复制或改写为另一种弹药。混装后最后装入的 profile 必须是下一发。

### 4.6 多弹种与有序载具回归

1. 在 JEI/REI 对 9 mm AP/HP、.45 ACP AP/HP、5.56×45 AP/HP、7.62×39 AP/HP、.308 AP/HP、.50 BMG AP 和 12 gauge slug 分别确认两段 Create 工艺：加热 Basin 的类型预制坯，以及同口径量规部署器的 profile blank 印刻；不能用同一套 Create 输入随机产出不同 die，也不能退回 Gunsmith Table 弹种选择。
2. 实作链路时，先在加热 Basin 将中性弹头毛坯与 AP/HP/Slug 的实体材料压成类型预制坯；再用部署器持有的对应口径量规印刻精确 profile blank，量规必须保留。用该 profile blank 校准对应 projectile die，并在单工件部署器中形成带精确 `CartridgeAmmoId` 与 `ProjectileType` 的弹头；四槽 Cartridge Assembly 必须拒绝把 AP 弹头装进 HP AmmoId、把 slug 弹头装进 shot 输出，或把错误口径弹壳混入。
3. 将 FMJ → AP → HP 逐发装入 9 mm 或 5.56×45 实体弹匣，装入枪并分别射击三发：服务端投射物 AmmoId、已击发壳 `CartridgeAmmoId` 和伤害/护甲忽略/穿透 profile 必须依次对应 HP → AP → FMJ（最后装入先供弹）。12 gauge shot → slug 则必须由 slug 产生一枚、而不是原霰弹数量的投射物。
4. 对已审计的桥夹和漏夹重复混装：桥夹转入固定仓、漏夹装入枪内、脚本上膛和最终射击都不得退化为基础 AmmoId；空漏夹仍按原规则真实弹出。不同口径、没有 `industry/ammo_profiles` 声明的 alternate AmmoId、输出槽堵塞或中途移动来源均必须 fail closed。
5. 创造/免费弹药策略不得把未知或不兼容 profile 写入载具；生存模式的即时背包操作只能从实际选定来源扣除已转入的数量。不存在重连、关闭容器或移动物品后继续执行的未完成后台事务。

## 5. 可复用模板与零件

Create 工艺应形成明确的“毛坯 → 中性模具体 → 实体量规选择 → 平台模具 → 成品组件”链：

1. 压实不同结构毛坯（机匣、枪机、枪管、击发组、复进组件毛坯）；
2. 只压实一种**中性组件模具体**，而不是用五条相同输入直接产出五种 `DieTargetKind`；
3. 部署器持有对应结构毛坯作为不消耗的几何量规，置物台/传送带只送入一枚中性模具体，选择机匣、枪机、枪管、击发组或复进组件模具体；
4. 部署器持有 AK、AR 或 Glock 装配模板，置物台/传送带只送入一枚已选几何的模具体，校准为平台模具；模板保留；
5. 部署器持有校准后的组件模具，置物台/传送带只送入一枚对应结构毛坯，压制该毛坯；模具保留；
6. 输出对应机匣、枪机组/套筒、枪管、击发组、复进组件。

弹壳/弹头模具也先由中性模具体压实；对应完整样枪只校准一次中性弹药基准量规，再由该可复用量规完成两枚模具的校准。模板、量规和组件都使用 NBT 身份；例如 AK 机匣不能代替 AR 机匣，Glock 枪身不能被 AR 机匣替代。

### 5.5 压实冲突与实体量规回归

1. 重载后检查日志：不得出现 `Ambiguous Create compacting recipes`，也不得出现 Create 的九种 Basin 输入上限错误；
2. 工作盆以钢板、黄铜片、黄铜粒压实出**中性** `tacz:magazine_blank`，并以独立 Basin 工艺形成中性供弹组件毛坯与中性供弹器规格量规毛坯；不得直接随机/按加载顺序产出某一平台弹匣；
3. 部署器持 AK/M4A1/HK416D 等任一兼容平台的**生产工装模板**，输入规格量规毛坯；模板必须保留，输出必须是对应族／弹种／容量的可复用规格量规。空的对应实体弹匣也应可被消耗性地逆向为同一量规；完整成枪不得出现在弹匣制造配方中；
4. 一个中性壳体毛坯与一个中性供弹组件毛坯应分别在单工件顺序线上由同一量规成型为命名子总成；最终部署只让壳体作为移动工件、消耗命名供弹组件，输出精确 `MagazineFamily` 和容量的空实体弹匣/弹链箱；
5. 中性组件模具体只能经对应结构毛坯量规选择出几何，再经 AK/AR/Glock/M1911/M9/MP5/UMP/P90/FAL 模板校准；中性弹壳/弹头模具体只能经同口径完整枪量规，或无对应枪时的专属机械合成器口径量规校准；
6. 默认包全部 24 种散装弹均应正常启动装配；专用机器必须只在四个独立槽位均匹配且数量达到定义批量时消耗对应数量的 NBT 弹壳、弹头、底火和推进药，并输出同批量对应弹药。40 mm/RPG 弹头的 TNT 战斗部在此前的顺序装配里消耗，不得被 GUI 静默忽略。

## 6. 最终枪械顺序装配（置物台单工件）

在 Create Fly 的传送带或置物台 + **部署器与动力冲压机交替**的生产线上测试，而**不是**在默认枪械工作台中把所有组件一次性交付：

| 成品 | 首个流动工件 | 后续终端工位（依序） |
|---|---|---|
| AK-47 | AK 机匣 | AK 模板（保留）→压合、枪机组→压合、枪管→压合、击发组→压合、复进组件→压合、**AK 外装套件**→最终压合 |
| M4A1 | AR 机匣组 | AR 模板（保留）→压合、枪机组→压合、枪管→压合、击发组→压合、复进组件→压合、**AR 外装套件**→最终压合 |
| Glock 17 | Glock 枪身 | Glock 模板（保留）→压合、套筒/枪机→压合、枪管→压合、击发组→压合、复进簧→压合、**Glock 外装套件**→最终压合 |
| M1911 | M1911 枪身 | M1911 模板（保留）→压合、套筒→压合、枪管→压合、击发组→压合、复进簧→压合、**M1911 外装套件**→最终压合 |
| M9A4 | M9 枪身 | M9 模板（保留）→压合、套筒→压合、枪管→压合、击发组→压合、复进簧→压合、**M9 外装套件**→最终压合 |
| MP5A5 / UMP45 / P90 / FAL | 对应机匣 | 对应模板（保留）→每个结构件逐件压合→**对应外装套件**→最终压合 |

外装套件的前段在机械合成器完成：原料 → 中性外装毛坯，再由部署器持对应蓝图校准为命名套件；它不属于终端传送带上的“原料安装”步骤。

预期：

1. 置物台/传送带上从开始到结束都只有首个组件变成的**一个**过渡工件；不得尝试把多种组件同时放到置物台；
2. 每个部署器只持一种模板、组件或命名外装套件。蓝图那一站有 `keep_held_item: true`，模板保留；每个主要组件部署后都必须紧接一台动力冲压机压合；原始木料/皮革/玻璃/黄铜必须先在机械合成器形成中性外装毛坯，再由蓝图校准成平台外装套件，终端线上不得出现“安装石头/木板/皮革”这类原料步骤；
3. 错平台、错零件、错模板的部署器不能推进工序；中断后的过渡件只能回到同一条序列继续，不能直接当成成枪或其他平台组件；
4. 最终输出必须是可正常开火的空枪，具有正确 `GunId` 和首个合法射击模式（自动枪为 `AUTO`，M1911/M9/FAL 等半自动枪为 `SEMI`）；
5. 成枪不免费附带散装子弹或弹匣，需另外生产并装填实体弹匣；
6. `CREATE_FLY` 下 AK/M4/Glock/M1911/M9/MP5/UMP/P90/FAL 的旧默认枪械工作台成枪条目不应出现。若工艺 JSON 缺失或形状校验失败，日志应警告且旧条目必须保留，而不能让枪不可获得。

REI 中该类别会汇总列出首工件与所有工位供料，显示 `D→P→…` 的实际工位顺序，并标注“置物台/传送带始终只有一个工件”；这表示**顺序**工艺，不表示这些输入同时占据一个置物台，也不表示只需一台机械手。

## 6.5 工业维护与 C 阶段回归

1. 保持默认 `IndustryMaintenanceScope = INDUSTRIAL_ASSEMBLY`。通过 Create 终端产出一把默认工业枪，首次手持后应获得 `IndustryMaintenanceSchema = 1`、五项 `IndustryCondition* = 10000`、`IndustryFouling = 0` 与 `IndustryMaintenanceShots = 0`；旧存档中已有工业来源标记、但尚无维护字段的枪也必须以相同满状态安全补齐。
2. Tooltip 应显示“良好 / 需保养 / 需维修 / 停用”之一及枪况、污垢百分比；持枪 HUD 的枪卡上方应有两条小条，分别表示最差组件枪况与污垢。它们读取保存的服务器 NBT，不得从枪械等级或普通物品耐久猜测。
3. 用实际消耗弹药的工业枪完成射击后，`IndustryMaintenanceShots` 才增加，五项 Condition 按该 GunId 的 `industry/maintenance/guns/*.json` 递减、Fouling 增加。创造模式未实际扣弹的免费射击不得磨损；非工业来源的战利品/命令枪在默认范围内不得被写入维护数据。
4. 通过测绘 Gunsmith Table 完成一把第三方 surveyed 枪；最终成枪必须带 `IndustryAssemblyPlatform = surveyed/...` 等完整工业来源标签，并以满状态进入同一维护可视化路径。
5. C.1：把工业枪最差组件调至 `critical_condition` 以下后，下一次触发必须在任何扣弹前返回 `JAMMED` 并写入 `IndustryJam = lockout`；拆解、维修、复装后才可解除。不能用换弹/拉栓、重新进服或客户端预测绕过。
6. C.2：仅对 `AI AWP`、`Kar98`、`M107`、`M700`、`M870`、`M95`、`SPAS-12` 的工业来源枪，把枪况调入 warning/critical 区间并提高 Fouling 后回归。命中确定性抽样的那一发必须照常发射、只扣一次真实弹药并随后写 `IndustryJam = feed`；下一次触发不得进入 `reduceAmmoOnce`。再次按开火键应发送清障请求并运行原有手动 bolt 动画；普通自动 bolt 不得清除。只有服务器 bolt 结束且膛内真实有弹时才清除 `feed`，失败/无弹时必须保留；HUD、Tooltip 和持有枪 NBT 应随 S2C 完整快照同步。所有 `clear_action = none` 的其余默认枪、surveyed 通用档和未知第三方枪不得随机写入 `feed`。
7. C.3 热/环境：对实际声明 `GunHeatData` 的工业枪（当前默认样本为 Minigun）比较冷态与高热态的真实扣弹射击；高热态的 Condition/Fouling 增量必须按 profile `heat_stress_multiplier` 提高，且没有 HeatData 的工业枪不得凭空获得热 NBT 或热倍率。分别在晴天、服务端确认淋雨、浸水/`#tacz:maintenance_wet_exposure` 接触、以及 `#tacz:maintenance_contaminants` 接触时射击，验证只由服务器位置/天气决定 rain/wet/污染倍率，且雨和浸没不重复叠加为客户端猜测的倍率。分别将 `IndustryHeatStressEnabled` 关闭、或将 HeatWear/FoulingScale 设为 0，确认只关闭热量额外部分，不关闭基础维护或环境倍率。
8. C.3 清洁：先在真实加热 Basin 用 2 个 `tacz:carbon_dust`、纸和黏液球制得 `tacz:maintenance_cleaning_kit`；再把安全清空的完整工业枪、匹配 production 模板、检具、扳手和足量套件放入工业勤务台的独立清洁材料槽，点击“清除污垢”。服务器应按 `ceil(Fouling / 2500)` 扣套件、将输出枪 Fouling 置 0、保留五项 Condition/Shot/附件隔离语义，并不得清除 `IndustryJam=feed` 或 `lockout`、不得走部署器/传送带/顺序装配。
9. C.4：把工业 AK/Glock/Minigun 等 `fault_mode = service_lockout` 枪调进自己的 warning/critical 区间并提高 Fouling/真实 Exposure，命中确定性抽样后当前一发必须照常发射，随后写 `IndustryJam = service_lockout`；下一次触发不得扣弹，Tooltip 必须显示机械勤务故障。它只能通过真实工业勤务台的拆解、维修、复装解除，不能用 R、普通 bolt 或客户端 NBT 绕过。`fault_mode = feed` 的 7 把手动动作枪仍走第 6 项的真实 bolt 清障。
10. 熟练度：把同一实体枪升至较高等级，Tooltip 必须显示实际 ADS/真实散布/后坐操控收益；服务器投射物散布与服务端/客户端 ADS 进度都应按 `GunExperience*` 配置变化，本地后坐镜头也应变化。关闭 HandlingEnabled 或将各项最大缩减设为 0 后对应收益应消失，且伤害、护甲穿透、维修材料和维护故障不得改变。
11. 仅在管理员明确把 `IndustryMaintenanceScope` 设为 `ALL_GUNS` 后，非工业来源枪才参与；其第一次迁移也必须从满状态、清洁状态开始。没有工业来源和实际勤务台出口的旧战利品不得被 C.4 随机 `service_lockout` 锁死。

## 7. 运行时自动识别回退

在 `CREATE_FLY` 档、`AutoDiscoverIndustryReplacements = true` 时：

1. 安装一个未提供 `industry/assembly` 声明的第三方枪包，选择其中的枪、弹药或配件工作台配方；
2. 打开枪械工作台、JEI 或 REI；
3. 预期：原结果仍可制造，但材料栏自动保留原枪包材料并追加对应工业门槛；枪械追加高碳钢板、组件毛坯、黄铜板，弹药追加弹壳毛坯、弹头毛坯、底火、推进药，配件追加高碳钢板、黄铜板；
4. 已声明平台（AK/M4/Glock/M1911/M9/MP5/UMP/P90/FAL）不走这个通用回退，而保留高保真组件路线；
5. 将 `AutoDiscoverIndustryReplacements` 设为 `false` 后重载，未声明内容应恢复原始材料表；
6. 日志应汇总自动替代的枪、弹药、配件数量，且不应修改枪包文件本身。

## 8. LEGACY 回退

把 `IndustryProfile` 改为 `LEGACY` 并重启/重载后确认：

- 原默认枪械工作台配方重新出现；
- Create Fly 工业终端配方不再接管默认枪包 53 把枪与 24 种散装弹药的 TACZ 工作台路径；
- 已存在的工业组件、模板、实体弹匣不会损坏存档。
