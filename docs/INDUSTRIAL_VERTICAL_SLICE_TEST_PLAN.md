# 工业制造纵切：材料、弹药与三平台装配测试

> 对应实现：Create Fly 工业链 Phase 2/3（AK、AR、Glock 首批平台）

## 前置

- 服务端配置：`IndustryProfile = "CREATE_FLY"`；
- Create Fly 必须在客户端与服务端加载；
- `PhysicalMagazines = true` 可同时测试实体弹匣；
- 本测试只覆盖 TACZ 内置 `tacz` 默认包，不改变任何第三方枪包配方。

## 1. 配方查看器桥接

- JEI 应继续显示 Create Fly 原生完整树；
- REI 应新增 TACZ 的工业研磨、工业粉碎、加热/炽热鼓风炉搅拌、机械冲压、**工作盆压实**、部署器成型和**顺序枪械装配**类别；
- 点击碳粉、硫粉、朱砂粉、钢板、零件、弹药或最终 AK/M4/Glock 时，应能沿输入/输出查到完整 TACZ 工艺链；顺序装配页必须标明置物台/传送带只有一个流动工件；
- REI 显示来自服务器同步的 `recipe/create/` 工艺投影，专用服务器也应可用；
- 重载日志中不得出现 `Ambiguous Create compacting recipes`，也不得出现 `ingredients type is too many, expected range [0-9]`。

## 2. Create Fly 基础材料链

按顺序在 REI/JEI 或 Create Fly 配方查看器中确认下列配方存在：

```text
煤 / 木炭 --研磨--> 碳粉
硫黄 / 强效硫黄 --粉碎--> 硫粉
朱砂 --研磨--> 朱砂粉
铁锭 + 碳粉 + 方解石 --加热搅拌--> 生铁
生铁 + 碳粉 + 石英 --炽热搅拌--> 高碳钢
高碳钢锭 --冲压--> 高碳钢板
碳粉 + 硫粉 + 红石 --加热搅拌--> 工业推进药
黄铜锭 --冲压--> 弹壳坯
黄铜粒 + 朱砂粉 + 硫粉 + 红石 --压实--> 底火组件
```

其中加热 Basin + Mechanical Mixer + Blaze Burner 是当前“鼓风炉单元”。它不是额外复制一台 TACZ 机器，而是明确要求 Create Fly 的热源、动力和加工物流。

## 3. 专用弹药装配机

确认弹药装配机 GUI 可按独立槽位产出带正确 `AmmoId` 的 TACZ 弹药：

- 9 mm；
- 5.56×45；
- 7.62×39；
- 12G；
- .45 ACP；
- .308；
- 5.7×28；
- 5.8×42。

先确认动力冲压机只会把黄铜锭/生铁压成中性弹壳毛坯/弹头毛坯；随后使用部署器持有对应口径、类型的冲压模具。部署器应保留模具，并把毛坯真正转换成带 `CartridgeCaliber` 的弹壳坯、带口径和 `ProjectileType` 的弹头坯。

在弹药装配机中分别放入：指定口径弹壳、指定口径/类型弹头、底火、工业推进药；点击“装配”。服务器必须只在四格同时匹配同一条 `industry/cartridge_assembly/*.json` 定义时扣料，并在成品槽输出一发对应弹药。错误口径、错误类型、错误底火/推进药、满成品槽都不得消耗任何输入。

自动化回归：从顶部或四个侧面用漏斗或 Create 物流送入上述材料，机器必须按物品身份路由到正确槽位；从底面只能抽取成品。给予红石信号后，进度条应在 40 tick 内完成一次装配；撤去信号、改坏输入或堵塞成品槽时进度必须归零且不扣料。产物必须能够：

1. 正确显示 TACZ 弹药名称与模型；
2. 正常装入实体弹匣；
3. 被对应枪械实际射击消耗。

在 `CREATE_FLY` 档，枪械工作台中原有的 9 mm、5.56×45、7.62×39、12G 默认散装弹药配方应不再出现，避免用铜锭/火药绕过工业链。

## 4. 可复用模板与零件

Create 工艺应形成明确的“毛坯 → 中性模具体 → 实体量规选择 → 平台模具 → 成品组件”链：

1. 压实不同结构毛坯（机匣、枪机、枪管、击发组、复进组件毛坯）；
2. 只压实一种**中性组件模具体**，而不是用五条相同输入直接产出五种 `DieTargetKind`；
3. 部署器持有对应结构毛坯作为不消耗的几何量规，置物台/传送带只送入一枚中性模具体，选择机匣、枪机、枪管、击发组或复进组件模具体；
4. 部署器持有 AK、AR 或 Glock 装配模板，置物台/传送带只送入一枚已选几何的模具体，校准为平台模具；模板保留；
5. 部署器持有校准后的组件模具，置物台/传送带只送入一枚对应结构毛坯，压制该毛坯；模具保留；
6. 输出对应机匣、枪机组/套筒、枪管、击发组、复进组件。

弹壳/弹头模具也先由中性模具体压实，再由部署器持相应口径的完整枪械作为不消耗的膛室量规完成校准。模板、量规和组件都使用 NBT 身份；例如 AK 机匣不能代替 AR 机匣，Glock 枪身不能被 AR 机匣替代。

### 4.5 压实冲突与实体量规回归

1. 重载后检查日志：不得出现 `Ambiguous Create compacting recipes`，也不得出现 Create 的九种 Basin 输入上限错误；
2. 工作盆以钢板、黄铜片、黄铜粒压实出**中性** `tacz:magazine_blank`，而不是直接随机/按加载顺序产出某一平台弹匣；
3. 部署器持 Glock 17、AK-47、M4A1、P90 等任一对应完整枪，输入 `magazine_blank`；枪必须保留，输出必须是该枪精确 `MagazineFamily` 和容量的空实体弹匣；
4. 把错误平台的枪放入部署器时，毛坯不得被校准成目标弹匣；
5. 中性组件模具体只能经对应结构毛坯量规选择出几何，再经 AK/AR/Glock/M1911/M9/MP5/UMP/P90/FAL 模板校准；中性弹壳/弹头模具体只能经对应口径枪械量规校准；
6. 9 mm、5.56×45、7.62×39、12G、.45 ACP、.308、5.7×28、5.8×42 装配均应正常启动；专用机器必须只在四个独立槽位均匹配时消耗一枚 NBT 弹壳、一枚 NBT 弹头、一枚底火和一份推进药，并输出一发对应弹药。

## 5. 最终枪械顺序装配（置物台单工件）

在 Create Fly 的传送带或置物台 + 多个部署器生产线上测试，而**不是**在默认枪械工作台中把所有组件一次性交付：

| 成品 | 首个流动工件 | 后续部署工位（依序） |
|---|---|---|
| AK-47 | AK 机匣 | AK 模板（保留）、枪机组、7.62 枪管、击发组、复进组件、4 木板 |
| M4A1 | AR 机匣组 | AR 模板（保留）、枪机组、5.56 枪管、击发组、缓冲复进组件、2 木板、2 皮革 |
| Glock 17 | Glock 枪身 | Glock 模板（保留）、套筒/枪机、9 mm 枪管、击发组、复进簧、2 皮革 |
| M1911 | M1911 枪身 | M1911 模板（保留）、套筒、.45 枪管、击发组、复进簧、2 皮革 |
| M9A4 | M9 枪身 | M9 模板（保留）、套筒、9 mm 枪管、击发组、复进簧、2 皮革、黄铜板 |
| MP5A5 | MP5 机匣 | MP5 模板（保留）、枪机组、枪管、击发组、复进组件、皮革、黄铜板 |
| UMP45 | UMP 机匣 | UMP 模板（保留）、枪机组、.45 枪管、击发组、复进组件、皮革、黄铜板 |
| P90 | P90 机匣 | P90 模板（保留）、枪机组、5.7 枪管、击发组、复进组件、皮革、玻璃板 |
| FAL | FAL 机匣 | FAL 模板（保留）、枪机组、.308 枪管、击发组、复进组件、木板、皮革 |

预期：

1. 置物台/传送带上从开始到结束都只有首个组件变成的**一个**过渡工件；不得尝试把多种组件同时放到置物台；
2. 每个部署器只持一种模板、组件或辅料。蓝图那一站有 `keep_held_item: true`，模板保留；其余工位各自消耗一个输入；
3. 错平台、错零件、错模板的部署器不能推进工序；中断后的过渡件只能回到同一条序列继续，不能直接当成成枪或其他平台组件；
4. 最终输出必须是可正常开火的空枪，具有正确 `GunId` 和首个合法射击模式（自动枪为 `AUTO`，M1911/M9/FAL 等半自动枪为 `SEMI`）；
5. 成枪不免费附带散装子弹或弹匣，需另外生产并装填实体弹匣；
6. `CREATE_FLY` 下 AK/M4/Glock/M1911/M9/MP5/UMP/P90/FAL 的旧默认枪械工作台成枪条目不应出现。若工艺 JSON 缺失或形状校验失败，日志应警告且旧条目必须保留，而不能让枪不可获得。

REI 中该类别会汇总列出首工件与所有工位供料，并显示“置物台/传送带始终只有一个工件”；这表示**顺序**工艺，不表示这些输入同时占据一个置物台。

## 6. LEGACY 回退

把 `IndustryProfile` 改为 `LEGACY` 并重启/重载后确认：

- 原默认枪械工作台配方重新出现；
- Create Fly 工业终端配方不再接管本轮九把枪与八种弹药的 TACZ 工作台路径；
- 已存在的工业组件、模板、实体弹匣不会损坏存档。
