# 工业制造纵切：材料、弹药与三平台装配测试

> 对应实现：Create Fly 工业链 Phase 2/3（AK、AR、Glock 首批平台）

## 前置

- 服务端配置：`IndustryProfile = "CREATE_FLY"`；
- Create Fly 必须在客户端与服务端加载；
- `PhysicalMagazines = true` 可同时测试实体弹匣；
- 本测试只覆盖 TACZ 内置 `tacz` 默认包，不改变任何第三方枪包配方。

## 1. 配方查看器桥接

- JEI 应继续显示 Create Fly 原生完整树；
- REI 应新增 TACZ 的工业研磨、工业粉碎、加热/炽热鼓风炉搅拌、机械冲压、**工作盆压实**、部署器成型、**真实多槽机械合成器**和**顺序枪械装配**类别；
- 点击碳粉、硫粉、朱砂粉、钢板、零件、弹药或最终 AK/M4/Glock 时，应能沿输入/输出查到完整 TACZ 工艺链；顺序装配页必须标明置物台/传送带只有一个流动工件，并显示 `D→P→…` 实际工位图例（D=部署器、P=动力冲压机、F=液体喷嘴），不能再只有模糊的机械手图标；
- REI 显示来自服务器同步的 `recipe/create/` 工艺投影，专用服务器也应可用；
- 重载日志中不得出现 `Ambiguous Create compacting recipes`，也不得出现 `ingredients type is too many, expected range [0-9]`。

## 2. Create Fly 基础材料链

按顺序在 REI/JEI 或 Create Fly 配方查看器中确认下列配方存在：

```text
煤 / 木炭 --研磨--> 碳粉
硫黄 / 强效硫黄 --粉碎--> 硫粉
朱砂 --研磨--> 朱砂粉
铁锭 + 碳粉 + 方解石 --加热搅拌--> 生铁
生铁 + 碳粉 + 石英 --炽热搅拌--> 高碳钢
高碳钢锭 --冲压--> 高碳钢板
碳粉 + 硫粉 + 红石 --加热搅拌--> 工业推进药
黄铜锭 --冲压--> 弹壳坯
黄铜粒 + 朱砂粉 + 硫粉 + 红石 --压实--> 底火组件
```

其中加热 Basin + Mechanical Mixer + Blaze Burner 是当前“鼓风炉单元”。它不是额外复制一台 TACZ 机器，而是明确要求 Create Fly 的热源、动力和加工物流。

## 3. 专用弹药装配机

确认弹药装配机 GUI 可按独立槽位产出带正确 `AmmoId` 的 TACZ 弹药。默认枪包全部 24 种散装弹必须都能查到一条 `industry/cartridge_assembly` 定义并完成一次装配：

- 手枪/PD：9 mm、.22 WMR、.45 ACP、4.6×30、5.7×28、7.62×25、.357 Magnum、.50 AE；
- 步枪/机枪：5.45×39、5.56×45、5.8×42、6.8×51 Fury、7.62×39、7.62×54R、7.92×57、.308、.30-06、.338、.45-70、.50 BMG；
- 霰弹：12G；
- 爆炸弹药：40 mm HE、RPG-7 HEAT 火箭。

其中无对应默认枪的 4.6×30、5.45×39、6.8×51 Fury、7.62×25、7.62×54R 应先在机械合成器制造各自的淬硬口径量规，再校准弹壳/弹头模具；不得出现使用错误枪械校准或同一 Basin 输入随机产出口径的路线。40 mm 与 RPG-7 弹头应显示 TNT 战斗部部署工位；.50 BMG 壳/弹头成型应各走“初始毛坯 + 3 枚额外毛坯 + 对应模具”的单工件顺序线，不能与 9 mm 同样只消耗一枚毛坯。

先确认动力冲压机只会把黄铜锭/生铁压成中性弹壳毛坯/弹头毛坯；随后使用部署器持有对应口径、类型的冲压模具。部署器应保留模具，并把毛坯真正转换成带 `CartridgeCaliber` 的弹壳坯、带口径和 `ProjectileType` 的弹头坯。

在弹药装配机中分别放入：指定口径弹壳、指定口径/类型弹头、底火、工业推进药；点击“装配”。服务器必须只在四格同时匹配同一条 `industry/cartridge_assembly/*.json` 定义且**四格数量均达到该定义批量**时扣料，并输出整批对应弹药。默认回归至少核对：9 mm 消耗 24 壳/24 弹头/24 底火/2 推进药并输出 24；5.56×45 为 16/16/16/3→16；.50 BMG 为 4/4/4/8→4；40 mm 为 1/1/1/2→1。错误口径、错误类型、错误底火/推进药、数量不足或满成品槽都不得消耗任何输入。

自动化回归：从顶部或四个侧面用漏斗或 Create 物流送入上述材料，机器必须按物品身份路由到正确槽位；从底面只能抽取成品。给予红石信号后，进度条应在 40 tick 内完成一次装配；撤去信号、改坏输入或堵塞成品槽时进度必须归零且不扣料。产物必须能够：

1. 正确显示 TACZ 弹药名称与模型；
2. 正常装入实体弹匣；
3. 被对应枪械实际射击消耗。

在 `CREATE_FLY` 档，默认枪包全部 24 种散装弹药的旧枪械工作台配方都不应再出现，避免以铜锭/火药或任何旧材料表绕过专用弹药装配机工业链；`LEGACY` 档则应完整保留它们。

### 3.5 模板探索与村民采购

1. 升级一名武器匠至大师；其 26.2 数据驱动 level-5 商品池应保留原版交易，并随机出现 TACZ 工业模板商品。模板花费绿宝石和一本书，交易结果必须是带精确 `IndustryPlatform` 的 `tacz:gun_blueprint`，不是成枪；
2. 检查武器匠/工具匠村庄箱、废弃矿井、要塞、掠夺者前哨、林地府邸、古城和试炼密室稀有奖励箱：应有概率出现一张随机工业模板；
3. 用交易或箱子得到的模板直接校准模具并参与总装，必须与旧压实路线得到的同平台模板完全兼容；旧模板压实配方仍应存在，作为不探索/不交易时的后备路线。

## 4. 真实抛壳与弹壳回收

以已工业装配的弹药分别测试 Glock 17（9 mm）、M870（12G）、Kar98（7.92×57）、M320（40 mm）和 RPG-7：

1. 对 `eject_case: true` 的枪，每次真正消耗一发后，应从射手**右侧**产生一个可见、可拾取的原生掉落物（面北时向东、面南时向西），而不是只有客户端短暂动画；连发、双管和霰弹每发只产出**一枚**完整弹壳/弹壳壳体，不能按 pellet 数倍增；
2. 掉落物必须是 `tacz:cartridge_case`，带 `IndustryPartKind=spent_case`、精确 `CartridgeCaliber`、`CartridgeAmmoId` 和 `SpentCartridgeCase=true`；玩家和漏斗均可回收，连续射击的同口径壳可按原版规则堆叠/合并；
3. 将回收的壳送上部署器置物台，并让部署器持有**相同口径**的 `case_die`：应转成对应的未装填 `IndustryPartKind=case`。错误口径模具、弹头模具或没有模具都不得使它变成可装填弹壳；
4. 整形后的壳必须仍需通过弹药装配机补充一枚新弹头、一枚底火和一份推进药；不能把 `spent_case` 直接塞进装配机，也不能复制弹药；
5. RPG-7 发射火箭时不应产生可回收弹壳（`eject_case=false`）。创造模式未实际消耗弹药时也不应凭空刷出可回收壳。
6. 分别检查 9 mm、12G、40 mm 的成型弹壳、成型弹头、重新整形壳与掉落 spent case：其 `minecraft:max_stack_size` 必须与同 `AmmoId` 的最终散装弹一致（预期分别为 60、36、6），而不是统一旧值 16。旧存档的壳/弹头放入玩家背包后也应自动校正。

### 4.5 工业回收、弹匣袋与装弹器

1. 制造工业回收站；从顶部/侧面只允许送入一件枪、实体弹匣或模具，底面只能抽取回收产物。红石信号下应在 40 tick 完成一次有效回收；
2. 将一只**空**实体弹匣送入：应输出 `magazine_blank`；带余弹弹匣不得被消耗。将已配置 case/projectile/component die 或口径量规送入：应回收高碳钢板和黄铜粒；
3. 用工业终端新制造一把空枪，先安装附件或插入实体弹匣分别测试：回收站必须拒绝且不消耗枪。退匣并拆下附件后，内置供弹/枪膛中的弹应以散装弹安全输出，同时输出三件结构毛坯和一块高碳钢板；旧工作台枪、战利品枪或没有 `IndustryAssemblyPlatform` 的同 GunId 枪不得回收工业零件；
4. 弹匣袋与装弹器配方的金属件应为 Create 的 `create:copper_sheet`，不得再要求高碳钢板；
5. 手持弹匣袋，在背包中右击已配置实体弹匣：最多收纳四只，余弹数必须保留。右击空槽或手持袋在空中右击应取出完整同一只弹匣；
6. 手持装弹器，在背包中右击一个实体弹匣：应从玩家主背包批量抽取相同 `AmmoId` 的散装弹，直至弹匣满或背包无匹配弹；错误弹种不得消耗，装弹器本身不得消耗。

## 5. 可复用模板与零件

Create 工艺应形成明确的“毛坯 → 中性模具体 → 实体量规选择 → 平台模具 → 成品组件”链：

1. 压实不同结构毛坯（机匣、枪机、枪管、击发组、复进组件毛坯）；
2. 只压实一种**中性组件模具体**，而不是用五条相同输入直接产出五种 `DieTargetKind`；
3. 部署器持有对应结构毛坯作为不消耗的几何量规，置物台/传送带只送入一枚中性模具体，选择机匣、枪机、枪管、击发组或复进组件模具体；
4. 部署器持有 AK、AR 或 Glock 装配模板，置物台/传送带只送入一枚已选几何的模具体，校准为平台模具；模板保留；
5. 部署器持有校准后的组件模具，置物台/传送带只送入一枚对应结构毛坯，压制该毛坯；模具保留；
6. 输出对应机匣、枪机组/套筒、枪管、击发组、复进组件。

弹壳/弹头模具也先由中性模具体压实，再由部署器持相应口径的完整枪械作为不消耗的膛室量规完成校准。模板、量规和组件都使用 NBT 身份；例如 AK 机匣不能代替 AR 机匣，Glock 枪身不能被 AR 机匣替代。

### 5.5 压实冲突与实体量规回归

1. 重载后检查日志：不得出现 `Ambiguous Create compacting recipes`，也不得出现 Create 的九种 Basin 输入上限错误；
2. 工作盆以钢板、黄铜片、黄铜粒压实出**中性** `tacz:magazine_blank`，而不是直接随机/按加载顺序产出某一平台弹匣；
3. 部署器持 Glock 17、AK-47、M4A1、P90 等任一对应完整枪，输入 `magazine_blank`；枪必须保留，输出必须是该枪精确 `MagazineFamily` 和容量的空实体弹匣；
4. 把错误平台的枪放入部署器时，毛坯不得被校准成目标弹匣；
5. 中性组件模具体只能经对应结构毛坯量规选择出几何，再经 AK/AR/Glock/M1911/M9/MP5/UMP/P90/FAL 模板校准；中性弹壳/弹头模具体只能经同口径完整枪量规，或无对应枪时的专属机械合成器口径量规校准；
6. 默认包全部 24 种散装弹均应正常启动装配；专用机器必须只在四个独立槽位均匹配且数量达到定义批量时消耗对应数量的 NBT 弹壳、弹头、底火和推进药，并输出同批量对应弹药。40 mm/RPG 弹头的 TNT 战斗部在此前的顺序装配里消耗，不得被 GUI 静默忽略。

## 6. 最终枪械顺序装配（置物台单工件）

在 Create Fly 的传送带或置物台 + **部署器与动力冲压机交替**的生产线上测试，而**不是**在默认枪械工作台中把所有组件一次性交付：

| 成品 | 首个流动工件 | 后续终端工位（依序） |
|---|---|---|
| AK-47 | AK 机匣 | AK 模板（保留）→压合、枪机组→压合、枪管→压合、击发组→压合、复进组件→压合、**AK 外装套件**→最终压合 |
| M4A1 | AR 机匣组 | AR 模板（保留）→压合、枪机组→压合、枪管→压合、击发组→压合、复进组件→压合、**AR 外装套件**→最终压合 |
| Glock 17 | Glock 枪身 | Glock 模板（保留）→压合、套筒/枪机→压合、枪管→压合、击发组→压合、复进簧→压合、**Glock 外装套件**→最终压合 |
| M1911 | M1911 枪身 | M1911 模板（保留）→压合、套筒→压合、枪管→压合、击发组→压合、复进簧→压合、**M1911 外装套件**→最终压合 |
| M9A4 | M9 枪身 | M9 模板（保留）→压合、套筒→压合、枪管→压合、击发组→压合、复进簧→压合、**M9 外装套件**→最终压合 |
| MP5A5 / UMP45 / P90 / FAL | 对应机匣 | 对应模板（保留）→每个结构件逐件压合→**对应外装套件**→最终压合 |

外装套件的前段在机械合成器完成：原料 → 中性外装毛坯，再由部署器持对应蓝图校准为命名套件；它不属于终端传送带上的“原料安装”步骤。

预期：

1. 置物台/传送带上从开始到结束都只有首个组件变成的**一个**过渡工件；不得尝试把多种组件同时放到置物台；
2. 每个部署器只持一种模板、组件或命名外装套件。蓝图那一站有 `keep_held_item: true`，模板保留；每个主要组件部署后都必须紧接一台动力冲压机压合；原始木料/皮革/玻璃/黄铜必须先在机械合成器形成中性外装毛坯，再由蓝图校准成平台外装套件，终端线上不得出现“安装石头/木板/皮革”这类原料步骤；
3. 错平台、错零件、错模板的部署器不能推进工序；中断后的过渡件只能回到同一条序列继续，不能直接当成成枪或其他平台组件；
4. 最终输出必须是可正常开火的空枪，具有正确 `GunId` 和首个合法射击模式（自动枪为 `AUTO`，M1911/M9/FAL 等半自动枪为 `SEMI`）；
5. 成枪不免费附带散装子弹或弹匣，需另外生产并装填实体弹匣；
6. `CREATE_FLY` 下 AK/M4/Glock/M1911/M9/MP5/UMP/P90/FAL 的旧默认枪械工作台成枪条目不应出现。若工艺 JSON 缺失或形状校验失败，日志应警告且旧条目必须保留，而不能让枪不可获得。

REI 中该类别会汇总列出首工件与所有工位供料，显示 `D→P→…` 的实际工位顺序，并标注“置物台/传送带始终只有一个工件”；这表示**顺序**工艺，不表示这些输入同时占据一个置物台，也不表示只需一台机械手。

## 7. 运行时自动识别回退

在 `CREATE_FLY` 档、`AutoDiscoverIndustryReplacements = true` 时：

1. 安装一个未提供 `industry/assembly` 声明的第三方枪包，选择其中的枪、弹药或配件工作台配方；
2. 打开枪械工作台、JEI 或 REI；
3. 预期：原结果仍可制造，但材料栏自动保留原枪包材料并追加对应工业门槛；枪械追加高碳钢板、组件毛坯、黄铜板，弹药追加弹壳毛坯、弹头毛坯、底火、推进药，配件追加高碳钢板、黄铜板；
4. 已声明平台（AK/M4/Glock/M1911/M9/MP5/UMP/P90/FAL）不走这个通用回退，而保留高保真组件路线；
5. 将 `AutoDiscoverIndustryReplacements` 设为 `false` 后重载，未声明内容应恢复原始材料表；
6. 日志应汇总自动替代的枪、弹药、配件数量，且不应修改枪包文件本身。

## 8. LEGACY 回退

把 `IndustryProfile` 改为 `LEGACY` 并重启/重载后确认：

- 原默认枪械工作台配方重新出现；
- Create Fly 工业终端配方不再接管默认枪包 53 把枪与 24 种散装弹药的 TACZ 工作台路径；
- 已存在的工业组件、模板、实体弹匣不会损坏存档。
