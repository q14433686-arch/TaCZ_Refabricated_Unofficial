## 玩家与包作者

- 游戏、加载器、库与模组要分别匹配：本候选是 **`1.2.0+fabric.26.1.2.R1` / Java 25 / Fabric Loader 0.19.3 / Fabric API 0.155.2+26.1.2 / Forge Config API Port 26.1.5**。不能装到 26.2、1.21.11 或 NeoForge。模组最低版本谓词按核心 1.2.0 检查。
- [`DEFAULT_PACK_120.tsv`](../DEFAULT_PACK_120.tsv) 记录实际打进 JAR 的每个默认包文件和上游 blob；[`RESOURCE_IMPORT_120.tsv`](../RESOURCE_IMPORT_120.tsv) 记录包外资产。4,176 个有效文件 = 1,596 个源码覆盖 + 2,580 个不可变 bundle 回退；8 条退役路径不准回流。229 个索引（70 枪、25 弹、126 配件、3 台、5 转接件）。[上游缺件](investigations/DEFAULT_PACK_120_SOURCE_GAPS.tsv)原有 246 项；本线移除 Glock 的旧抽枪音效引用后剩 245 项，不是新造一个音效来凑数。代码、默认包、MAE 与重定位的小模型库[分别署名与授权](../LICENSES.md)。
- [转换步骤](GUNPACK_CONVERSION_26_1_2.md)：目录或 ZIP，先 `check` 再 `export`。目标层 `compat_26_1_2`、DFU 3465 → 4790、目标已绑定的注册表和 codec。导出不覆盖源包，不用 26.2 的 DataVersion，格式通过不等于游戏通过。升级时编辑过的默认目录进入 `tacz_backup/tacz_default_gun/backup-*.zip`；自制内容仍请单独命名并备份。
- 原版配方书收到铁块会解锁枪匠台的 **3×3 有序配方**；202 条专用配方属于包里的枪匠台、弹药台和配件台，不是把 202 个产物都塞进原版合成。查看器的选方只负责导航；库存和产物由服务端确认。
- 个人视模和 HUD 在暂停菜单的调节页，或在控制设置里给“视图调节”绑定按键（默认不占键）。保存路径 `config/tacz/view-profiles/<账号 UUID>.json`；HUD 由单枪规则、枪类规则、账号默认依次回退。独立卸弹键也默认不占键，兼容 Alt + 已绑定的装填键。模组内枪械与动画时间是会话玩法时间，不是现实时间。
- 瞄具沿用本线两份深度副本。经典 / 镜片重投影 / 可选窄视场重渲染不是同一项；后者会改动共享的 `LevelRenderState`，回到主遍前要重新提取。热源来自实际提交的模型表面，并与场景深度比对；分划来自原包模型。单看瞄具截图、全屏 HUD 或包名均不能证明这两条正确。

### 上手使用

| 要做什么 | 游戏里的做法与边界 |
|---|---|
| 存放物品 | 铁 / 金 / 钻石弹药库容量为 **216 / 432 / 864 组**。空手使用打开库存；持已指定弹种的普通弹药盒使用是补给，潜行使用则把盒中库存移回。改名等组件不同的散装弹是不同库存，不会为填盒而剥掉组件。含库存的库升级或掉落时应只有一份库存。 |
| 装拆与制作 | 原厂虚拟件不是背包物品，拆下不应凭空增加实体配件；真实件仍走服务端结算。制作先确认所开的台及包定义的产物范围；相同物品注册名的台用栈内 `BlockId` 区分，改名不会变成另一种台。JEI/REI 的“+”在专用台用于**定位配方**，不是免费领取或自动消耗材料。 |
| 调视野与镜片 | 全屏倍率用经典模式。想让镜外保持宽视野，可在客户端打开 `ScopePipEnable`；到了 `ScopePipMinMagnification` 才走 PIP。光影下还需 `ScopePipAllowShaderPacks`。`ScopePipRerender` 是额外一次世界渲染，开销和兼容性不同。`EnableExperimentalScopeLens`、`EnableScopeThermal` 是独立的镜片 / 热源开关。 |
