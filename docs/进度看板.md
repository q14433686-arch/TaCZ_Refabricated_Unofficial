# TACZ 深度重构 — 进度看板

> 最后更新：2026-07-31
> 
> **阶段顺序调整说明**：原P2(制造链)→P3(弹药)→P4(过热)调整为P2(弹药力学)→P3(过热/保养)→P4(制造链)。
> 理由：内部机制先定型，再造工厂。弹药力学决定过热/炸膛的触发条件，过热/保养决定枪的运行时行为，制造链最后实现。
> 
> **集成阶段说明**：P1-P3各系统独立完成后，需要将它们接入TACZ的射击流。此集成工作在P1-P3完成后统一进行。
