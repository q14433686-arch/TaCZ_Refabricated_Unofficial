## Investigate-only — leave for next round

### TACZ 3P muzzle lock vs existing PAL — **no-go this round**

Official 0.4.3 changelog: TACZ third-person hold locked the muzzle. Official LR registers a global player_animator **rotation** layer (`AdjustmentYRotModifier`) on every player and always pitches `leftArm`/`rightArm`. TACZ PAL here already skips arm pitch when `GunDisplayInstance#is3rdFixedHand`. This port has **no** LR rotation layer, so the official bug cannot fire. Next round should only add the exemption if/when an LR rotation layer is introduced.

### Melee 3P player_animator — **no-go this round**

Official stack: `PlayerAnimatorIntegration` (upper/lower/rotation), `MeleeAnimationListener`, `IdleAnimationHandler`, `ThirdPersonAnimationConfig` on display JSON, mixin into TACZ `PlayerAnimatorAssetManager`, `PlayerModelMixin` 1P arm reset. Needs content-pack player_animator files, can fight TACZ PAL layers, and is not required for the 1P Bedrock/Lua path already in this port.
