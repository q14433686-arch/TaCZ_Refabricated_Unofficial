# 精细材质 / 专用图需求目录

> 本文件把“能正常显示”与“已有对应型号的精细美术”分开。它不创建假物品、不会把 NBT
> 样本冒充真实制造，也不会因缺图改变服务器供弹、库存或配方行为。

## 如何读取本目录

- **精确图**：该 ItemStack 身份已有专用图；
- **家族复用图**：同机构/同材料族可见，但不是该型号的精确网格或贴图；
- **中性图**：功能真实、物件可见，但只是通用弹匣、弹链箱或中性工业件；
- **未声明 / 动态测绘**：没有可授权的固定身份图，只能诚实使用标准材质族，不能按名字或模型猜一张专用图。

“缺精细材质”不等于“紫黑缺图”。后备图保证玩家不会看见空白物品；本目录记录的是后续需要获得授权图源、制作专用图或由枪包作者提供 `industry_icons` 映射的工作。

## C. 动态测绘弹药与枪械

运行时发现的第三方 AmmoId 会生成“测绘口径”量规、弹壳、弹头和已击发壳。它们不能在仓库里预先列成假精确美术，因为实际身份取决于玩家安装的枪包。

- 玩家界面使用已同步 AmmoIndex / GunIndex 的**原枪包正式名称**；
- 未提供精确资源时使用标准测绘材质族；
- 枪包作者可提供 `assets/<namespace>/industry_icons/*.json`，以精确 `AmmoId` / `CartridgeCaliber` / `IndustryPartKind` 绑定自己有授权的图；
- 不得从口径、模型、名字或一张猜测 JSON 自动借用另一把枪的图。

1. 先补玩家最常遇到的 305 个第三方载具中的常用 family；
