# P1 实现记录：供弹操作原语 & 状态机

> 实施日期：2026-07-31
> 阶段：P1 枪械状态机与模块化耐久

## 1. 概述

P1 从"供弹操作原语"开始，而不是直接写状态机。先封装最底层的操作函数，
状态机只负责调度这些原语，不直接操作弹药数据。

## 2. 新增文件清单

### 2.1 FeedResult — 操作结果密封接口

| 文件 | 路径 | 说明 |
|------|------|------|
| FeedResult | `api/item/operation/FeedResult.java` | 5个结果记录：StripResult/ChamberResult/ExtractResult/EjectResult/InsertResult |

每种结果类型都有 `ok()` / `fail*()` 工厂方法，携带成功/失败状态和副作用数据。

### 2.2 FeedOperation — 供弹操作原语

| 文件 | 路径 | 说明 |
|------|------|------|
| FeedOperation | `api/item/operation/FeedOperation.java` | 5个静态原语方法 + 7种供弹具的stripNextRound实现 |

5个原语：

| 原语 | 说明 | 失败时对应的MalfunctionType |
|------|------|---------------------------|
| stripNextRound | 从供弹具取出下一发 | FAILURE_TO_FEED / DOUBLE_FEED |
| chamberRound | 推弹入膛 | FAILURE_TO_FEED |
| extractFromChamber | 从枪膛抽壳 | FAILURE_TO_EXTRACT |
| ejectCase | 抛出弹壳 | FAILURE_TO_EJECT |
| insertRound | 压入供弹具 | —（非故障，返回原因） |

7种供弹具的 stripNextRound 实现：

| 供弹具 | 取弹方式 | 特殊逻辑 |
|--------|---------|---------|
| BoxMagazineData | LIFO取末尾 | springFatigue检查 + 每次供弹增加0.001 |
| TubularMagazineData | FIFO取头部 | 可靠性极高0.98 |
| CylinderData | 旋转对齐 | 不"取出"弹药，读取对齐弹膛的弹药 |
| BeltData | FIFO取头部 | linkReliabilityModifier检查 |
| StripperClipData | 一次性全部取出 | stripAll()后标记isConsumed |
| EnBlocClipData | FIFO取一发 | 取完最后一发触发autoEject |
| DrumMagazineData | LIFO取末尾 | springFatigue + windingTension检查 + 每次各增加0.001/0.005 |

### 2.3 GunCycleTransition — 状态机转换表

| 文件 | 路径 | 说明 |
|------|------|------|
| GunCycleTransition | `api/item/operation/GunCycleTransition.java` | 合法转换表 + 验证方法 |

合法转换表：

```
READY → FIRING          (扣扳机)
FIRING → UNLOCKING      (膛压建立，枪机开锁)
UNLOCKING → EXTRACTING  (枪机后拉，抽壳)
EXTRACTING → EJECTING   (弹壳被抛出)
EJECTING → FEEDING      (新弹推送入膛)
FEEDING → LOCKING       (枪机闭锁)
LOCKING → READY         (闭锁完成)
LOCKING → EMPTY         (弹匣空)
EMPTY → BOLT_OPEN       (手动拉栓/空仓挂机)
BOLT_OPEN → FEEDING     (手动推栓)
BOLT_OPEN → EMPTY       (弹匣空)
READY → BOLT_OPEN       (手动拉栓排弹)
任何 → MALFUNCTION       (原语失败)
MALFUNCTION → EMPTY     (清除故障后)
BOLT_OPEN → BOLT_CLOSE  (手动推栓)
BOLT_CLOSE → READY      (闭锁完成)
BOLT_CLOSE → EMPTY      (弹匣空)
```

### 2.4 GunCycleMachine — 射击循环状态机

| 文件 | 路径 | 说明 |
|------|------|------|
| GunCycleMachine | `api/item/operation/GunCycleMachine.java` | 3个循环方法 + 概率计算 |

3个循环方法：

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| fireAutoCycle | 完整自动射击循环 | 自装填枪械（半自动/全自动） |
| manualBoltCycle | 手动拉栓循环 | 栓动枪/泵动枪 |
| clearMalfunction | 清除故障 | 所有枪械 |

fireAutoCycle 完整流程：
```
前置检查：READY + 膛内有弹
→ FIRING: 击发（哑弹/炸膛/Squib判定）
→ UNLOCKING: 枪机开锁
→ EXTRACTING: 抽壳（抽壳失败判定）
→ EJECTING: 抛壳（抛壳失败判定）
→ FEEDING: 取弹入膛（进弹失败判定）
→ LOCKING: 闭锁
→ READY（弹匣空则进入EMPTY）
```

manualBoltCycle 完整流程：
```
前置检查：转换合法性
→ BOLT_OPEN: 拉栓
→ 如果膛内有弹壳：抽壳→抛壳
→ FEEDING: 从供弹具取弹入膛
→ LOCKING: 闭锁
→ READY（弹匣空则进入EMPTY）
```

## 4. 概率计算参数

| 判定 | 基础概率 | 影响因素 |
|------|---------|---------|
| 哑弹/不发火 | 0.1% | 撞针磨损 + 弹壳变形/锈蚀 + 减装药 |
| 抽壳失败 | 0.5% | 弹壳裂纹/变形/锈蚀 + 腐蚀性弹药 |
| 抛壳失败/烟囱 | 0.5% | 弹壳变形 |
| 进弹失败 | 供弹具可靠性 × 综合可靠性 | 弹簧疲劳 + 供弹口损伤 + 发条张力 |
| 炸膛 | getCatastrophicRiskAssessment() | 装药过量 + 枪管损伤 + 枪管异物 + 烧蚀 |
| Squib弹头卡管 | 30%（减装药时） | 减装药 |

所有概率受 reliabilityModifier 修正（来自公差/磨损/保养等）。
