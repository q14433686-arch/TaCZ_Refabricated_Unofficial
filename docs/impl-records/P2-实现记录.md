## 实现概览

P2实现了弹药内部力学和弹道扩展的核心系统，包括：
1. 弹壳材质扩展（新增POLYMER）
2. 底火类型扩展（新增MAGNUM）
3. 发射药类型扩展（新增DOUBLE_BASE/TRIPLE_BASE）
4. 弹头类型扩展（新增INCENDIARY）
5. 膛压计算模型（ChamberPressure）
6. 初速计算模型（MuzzleVelocityCalculator）
7. 弹头稳定性计算（StabilityCalculator / Greenhill公式）
8. 终端弹道计算（TerminalBallistics / 穿透/跳弹/伤害）
9. 综合弹道计算器（BallisticCalculator）
10. 弹壳掉落实体（EntityCasingDrop）
11. 弹道全局配置（BallisticsConfig）
12. GunData扩展（枪管长度/缠距/枪管材质）

## 核心设计决策

### 1. 膛压模型（ChamberPressure）
- 峰值膛压 = P_max_safe × charge_ratio² × powder_energy × primer_energy × barrel_factor
- charge_ratio使用二次方关系（装药量与膛压近似二次方）
- 炸膛概率 = base_rate × overpressure_ratio² × barrel_wear_factor × 100
- 超压比例与炸膛概率的关系：二次方增长（超压100%→概率约1%，超压200%→概率约4%）

### 2. 初速模型（MuzzleVelocityCalculator）
- V₀ = V_base × √(L_barrel/L_optimal) × √(charge×energy_density) × 1/√(mass) × primer
- 短枪管：初速按√(L/L_opt)降低
- 长枪管：初速增益递减（上限1.1倍）
- 亚音速弹初速上限340 m/s
- 发射药燃速匹配：快燃药配长枪管→过压风险(+5%炸膛概率)；慢燃药配短枪管→初速-10%

### 3. 稳定性模型（StabilityCalculator）
- Greenhill公式：Sg = 150 × D² / (T × L)
- D: 口径(mm→英寸)，T: 缠距(英寸/转)，L: 弹头长度(英寸)
- Sg > 1.5: 完全稳定，无惩罚
- 1.0 < Sg ≤ 1.5: 边缘稳定，+10%散布
- 0.5 < Sg ≤ 1.0: 不稳定，+100%散布，+20%伤害（翻滚）
- Sg ≤ 0.5: 严重失稳，+400%散布，-20%伤害

### 4. 终端弹道（TerminalBallistics）
- 穿透力 = base_pierce × bullet_type_modifier × velocity_ratio × distance_factor
- 跳弹条件：命中角度 < 15° AND 目标硬度 > 弹头硬度
- 跳弹后伤害30%，速度50%
- 穿透后伤害衰减30%~100%

### 5. 弹壳掉落（EntityCasingDrop）
- 射击后弹壳从抛壳口位置弹出
- 物理模拟：重力+阻力+碰撞反弹
- 5秒后自动转化为ItemEntity
- 玩家可拾取，用于复装系统

## 数据流

```
射击触发
  ├── BallisticCalculator.calculate() → BallisticResult
  │     ├── MuzzleVelocityCalculator → 初速
  │     ├── ChamberPressure → 膛压/超压/炸膛概率
  │     ├── StabilityCalculator → 稳定性/精度修正
  │     └── PowderType → 积碳/烧蚀/热量/烟雾/枪口焰
  ├── EntityKineticBullet → 使用初速和gravity/friction
  ├── CasingDropHelper.spawnCasing() → 弹壳实体
  └── GunWearData → 磨损消耗（关联P1）
```

## 与P3的接口

P2弹药力学为P3（过热/炸膛/保养）提供以下输入：
- `ChamberPressure.calculatePeakPressure()` → 膛压，用于过热判定
- `ChamberPressure.calculateCatastrophicFailureProbability()` → 炸膛概率
- `ChamberPressure.getOverPressureRatio()` → 超压比例
- `PowderType.getCarbonFoulingRate()` → 积碳速率，用于保养系统
- `PowderType.getErosionRate()` → 烧蚀速率，用于枪管磨损
- `PowderType.getHeatModifier()` → 热量产生系数，用于过热系统
- `BallisticResult.isCorrosive()` → 腐蚀性判定，用于保养系统

## 集成记录（射击流接入）

### EntityKineticBullet 修改

1. **新增字段**（6个）：
   - `loadedRound` — 当前弹药的完整数据（用于终端弹道计算）
   - `stabilityFactor` — 弹头稳定性因子（Sg）
   - `ballisticCoefficient` — 弹道系数（影响空气阻力）
   - `ballisticsInaccuracyModifier` — 精度修正系数
   - `isIncendiary` — 燃烧弹标记

2. **新增方法** `applyBallistics()`：
   - 接收 LoadedRound、CartridgeType、barrelLength、twistRate、bulletLength、GunData
   - 调用 BallisticCalculator.calculate() 获取 BallisticResult
   - 应用枪管材质初速修正
   - 应用稳定性精度修正
   - 应用弹道系数阻力修正
   - 设置燃烧弹标记

3. **修改 tick()**：
   - 空气阻力计算中增加弹道系数修正：`friction = this.friction * (0.3f / max(0.01f, ballisticCoefficient))`
   - 弹道系数越高，阻力越小（更流线型/更重的弹头）

4. **修改 getDamage()**：
   - 加入稳定性伤害修正：`stabilityDamageModifier * shotDamageMultiplier`
   - 翻滚弹头(+20%伤害)和严重失稳弹头(-20%伤害)的影响

5. **修改 onHitEntity()**：
   - 燃烧弹额外点燃效果：+4秒点燃时间 + 火焰粒子

6. **修改序列化**（writeSpawnData/readSpawnData）：
   - 新增 stabilityFactor、ballisticCoefficient、ballisticsInaccuracyModifier、isIncendiary、loadedRound 的序列化

### ModernKineticGunScriptAPI.shootOnce() 修改

1. **读取枪膛弹药数据**：
   - 从 `itemStack.get(ModDataComponents.GUN_STATE_DATA)` 获取 `GunStateData`
   - 从 `gunStateData.chamberedRound()` 获取 `LoadedRound`
   - 从 `gunData.getChamberedCartridge()` 获取口径ID，通过 `CartridgeTypeManager` 解析为 `CartridgeType`
   - 从 `gunData.getBarrelLength()` / `getTwistRate()` 获取枪管参数

2. **弹道应用**：
   - 在子弹创建后调用 `bullet.applyBallistics(chamberedRound, cartridgeType, barrelLength, twistRate, bulletLength, gunData)`

3. **弹壳掉落**：
   - 在所有子弹生成后，检查 `world instanceof ServerLevel`
   - 调用 `CasingDropHelper.spawnCasing(serverLevel, shooter, chamberedRound)`

### 兼容性

- **向后兼容**：如果 `GunStateData` 不存在或 `chamberedRound` 为 null，所有新逻辑被跳过，使用旧TACZ逻辑
- **性能**：弹道计算在子弹创建时执行一次（O(1)），不在tick中重复计算
- **网络同步**：新字段通过 `writeSpawnData`/`readSpawnData` 同步到客户端
