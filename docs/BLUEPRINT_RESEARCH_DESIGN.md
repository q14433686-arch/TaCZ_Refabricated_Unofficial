# 工业蓝图：发现、解读与生产模板

> 状态：待实现设计，2026-08-06  
> 范围：只重做蓝图的**获得与解读**；不推翻既有的 Create 单工件装配、模具校准及零件链。

## 1. 问题与结论

现有实现把 53 张平台蓝图都做成了：

```text
2 张纸 + 黄铜板 + 一种矿物 -> 对应蓝图
```

同时又把随机蓝图塞入大师武器匠与大量世界箱。前者让“蓝图”退化为配方查看器里可直接点出的材料表，后者则变成没有明确目标的重复随机掉落；两者并存没有形成进度。

**结论：删除“直接压实得到任意成品蓝图”的路线。**

蓝图不是一次性消耗的配方材料，而是生产线必须持有的可复用工装。因此不采用纯玩家技能树，也不让“玩家已学会”直接绕过部署器中的实体蓝图。正确模型是：

```text
野外/商人得到的「未解读技术档案」
  -> 在研究台解读，登记到玩家档案
  -> 生成/认证一张可放进部署器的「生产模板」
  -> 模板可反复校准模具、外装并参与终端装配
```

玩家的知识与工厂的物理模板是两个对象：前者回答“这个玩家是否已掌握技术”，后者回答“这条自动化生产线是否装了对应工装”。这样多人服、交易与自动化都成立。

## 2. 三种物品状态

不新增 53 种注册物品；继续使用 `tacz:gun_blueprint`，以 custom data 区分状态：

| 状态 | 核心 NBT | 来源/用途 |
| --- | --- | --- |
| 未解读档案 | `IndustryPlatform`、`IndustryPartKind=blueprint`、`BlueprintState=archive` | 世界战利品、村民、任务奖励；只能研究，不能放进部署器 |
| 已掌握技术 | 玩家持久化数据 `TaczBlueprintKnowledge` | 研究成功后按玩家 UUID 保存；用于研究台界面、重制模板与后续进度展示 |
| 生产模板 | 上述 NBT + `BlueprintState=production` | 研究台用档案和材料制出；唯一可作为 Create 部署器的蓝图输入 |

生产模板本身不消耗。它不是“再抽到一张一样的纸”，而是工厂真正使用的认证工装。

## 3. 研究台：唯一的学习入口

新增一台 **蓝图研究台**，不把学习塞进潜行右键或聊天命令。

### 界面与交互

```text
[ 技术档案 ] + [ 书与笔 / 墨囊 ] + [ 黄铜板 ] -> [ 生产模板 ]
                         |
                    研究进度 / 已掌握
```

- 左槽只接受 `BlueprintState=archive` 的档案；
- 辅料使用书、墨囊与少量黄铜，表达“转录、校核、制版”；
- 成功时服务端将平台写入该玩家的持久化知识；
- 输出一张同平台 `BlueprintState=production` 的实体模板；
- 首次研究消耗档案；已掌握的玩家可用对应的研究记录 + 辅料重制生产模板，防止模板丢失导致永久卡档；
- 研究和重制均由服务端处理，客户端不能伪造平台或绕过玩家知识检查。

选择单独方块而不是右键物品的原因：它能清楚展示档案、材料和产物的关系，也为“已掌握清单 / 推荐去向 / 重制”预留 UI 空间，不会再把复杂说明挤到普通物品 tooltip 中。

## 4. 获得路径分层

### 4.1 基础平台：确定性而非抽卡

首批必需平台（Glock、AK、AR）必须至少各有一条明确、可预期的路线：

- 固定阶段的武器匠订单，或；
- 指定低/中期结构箱的保底档案，或；
- 以后研究台的“基础目录”任务。

目标是让玩家能明确规划第一把枪，而不是在 53 个候选交易里刷新村民。

### 4.2 高级平台：探索的真实奖励

反器材、重机枪、爆炸武器、稀有手枪/精确枪等档案放入与其等级匹配的战利品池：

- 前哨、要塞、府邸：中级平台；
- 古城、试炼密室稀有奖励：重型/特殊平台；
- 不让所有箱子用同一个 35% 随机池。

每个箱池应按平台类别加权，并避免向已掌握玩家高频投放重复档案。重复档案后续可在研究台拆成“技术残页”，用于重制或交换。

### 4.3 村民：兜底与目标采购

不再把 53 个蓝图都追加到大师武器匠的随机 trade set。村民只提供：

- 基础平台的确定性目录；
- 少数轮换的中级档案；
- 重复档案的回收/交换服务。

这样村民是可靠的进度兜底，而非随机刷取器。

## 5. 平台收敛

现有 53 张单枪蓝图最终应收敛到约 8–12 个制造平台：AK、AR、Glock、M1911、M9/P320、MP5/UMP、P90、FAL/G3、栓动、霰弹、重型/反器材、爆炸武器等。

这不要求现在删除每把枪的独立零件。枪械差异仍由机匣、枪机、枪管、外装件和工艺序列保证；收敛的是“技术档案/工装”粒度，避免一张蓝图只服务一把枪的碎片化收藏。

## 6. 分期

### Phase A — 先让蓝图成为真正的技术物

1. 增加 `BlueprintState` 与玩家知识持久化服务；
2. 增加研究台、服务端研究事务和最小 UI；
3. 部署器工艺只接受 `BlueprintState=production`；
4. 删除 53 条直接压实成品蓝图配方；
5. 将当前村民/箱子输出改为 `archive`。

### Phase B — 修正可控来源

1. 基础 Glock / AK / AR 档案改为确定性路线；
2. 将世界箱改为按阶段和平台类型的池；
3. 实现重复档案回收或交换。

### Phase C — 收敛单枪档案

1. 为默认 53 把枪声明平台族；
2. 迁移工艺中 Blueprint NBT 的精确匹配规则；
3. 保留旧单枪档案的存档兼容映射，不使已有模板失效。

## 7. 不做的事

- 不让“玩家学会后”直接跳过 Create 部署器持有实体模板；
- 不让蓝图成为每造一把枪就消耗一次的普通材料；
- 不把所有说明塞进弹药装配机或回收站 UI；
- 不在 Phase A 用 53 个随机村民条目冒充技术进度。
