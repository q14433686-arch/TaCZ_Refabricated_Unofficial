## 2. 「不搬」清单（纪元裁定，勿回补）

- **26.2 线的 PIP**（`ScopePipRenderer/Target/Trace` + Iris/Voxy compat，render-target 版）：指导 §2 定案不搬；1211 线是本分支深度架构的对应物。
- **`GlCommandEncoderScopeDepthCopyMixin` 的 +39 行（`needsForcedAlwaysDepth` + GL_ALWAYS 补丁）**：1.21.11 专属 workaround（其 `DepthTestFunction` 无 ALWAYS）。26.1.2 的 `CompareOp` 原生有 `ALWAYS_PASS`，本分支 `ScopeRenderTypes` 已用 `DepthStencilState(ALWAYS_PASS, ...)` 直接声明，补丁无必要。
- **`scope_body.vsh`**：1211 仓库里同样无任何引用（死文件），不带入。
- **`IrisCompat` 的 ±100 行**：1211 的版本门（1.10.7 时代）与本分支不同；PIP 只消费 `isUsingRenderPack()`/`supportsFinalScopeOverlay()`，本分支两者齐备（26.1 门=Iris 1.11），零改动。
- `BedrockRenderSnapshot`、`ScopeRenderTypes`、`ClothConfigScreen` 等的 diff 均为纪元噪声，未动。

## 3. 三雷区落实（指导 §2）

1. **FOV 门禁用当前 tick 插值 aiming progress**：`suppressesWorldFovZoom(partialTicks)` 由 `CameraSetupEvent` 用 `event.getPartialTick()`（与其回落分支同一插值进度）调用；`isAimingStarted`/`shouldDeferReticleOverlay` 同源。类注释保留了 1211 的边界帧分析（固定 0/1 tick 在进出边界各漏一帧整屏变焦）。
2. **抓帧源与合成层次按 1211 终版**：vanilla=手部 HEAD 抓干净世界色、RETURN 合成，其后 picture→reticle→shade（`renderAfterFinalComposite` 在 `hasPendingOverlay()||isEnabled()` 门下 flush）；Iris=`finalizeLevelRendering` TAIL 先抓成品帧再合成再覆盖层（`ScopePipAllowShaderPacks` 门，默认 false）。BedrockAttachmentModel 的 reticle/rim 顺序修复（2026-08-13 实机反馈）与裸镜框入队一并带入。
3. **`SCOPE_PIP_ALLOW_SHADER_PACKS` 默认 false 不许绕**：`RenderConfig` 定义 `false`；`irisCompatible()`/`needsIrisWorldDepthCopy()`/`captureSceneAfterIrisFinal` 全部走该开关，无旁路。B1 二次渲染额外硬拒 Iris（`IrisCompat.isUsingRenderPack()` 直接 return false）。

## 4. 验收矩阵（实机前全标「未验证」）

按三份 STEP 剧本 + RERENDER 计划执行；26.1.2 特有新增项：

1. STEP1（深度备份判据）：既有 scope_mask 链路回归（应在 PIP 全关时零变化）。
2. STEP2（品红诊断）：`gradlew runClient -PtaczScopeDebug=true`，孔径纯品红、镜外无污染；**26.1.2 新风险**：借用式 `GlTexture`（DEPTH32 元数据 vs 实际 GL_DEPTH24_STENCIL8）过 `bindTexture` 的真实 GL 绑定行为。
3. STEP3（真实 PIP）：`-PtaczScopePip=true` + 配置 `ScopePipEnable`；进出 ADS 无 POV 跳变（插值门）、镜外 1×、镜内 Z×、`WorldZoomShare` 分摊、`Sharpness` 锐化、`DebugNoComposite`/`DebugPaintLens` 两条诊断、准星与遮光罩在镜内画面之上（顺序修复 + 延迟覆盖层）、退出后无残留贴片。
4. Iris 变体（默认关）：`ScopePipAllowShaderPacks=true` + Iris 1.11.x —— 成品帧抓取点、满 ADS 门（0.995）、world depth 私拷强制。
5. B1 二次渲染（默认关）：`ScopePipRerender=true` —— 镜内原生分辨率窄 FOV、镜外宽 FOV 覆盖、mesh 枪镜内外一致（`isInsideScopeLevelRender` 真标志后 `shouldSubmitGpuWorld` 拒收 + flush 画但不清表）、**已知风险：一帧两遍 renderLevel 的逐帧状态推进（26.2 曾记「镜外实体偶发消失」未查明）**。
6. 回归：PIP 全关时，整屏变焦路径、mesh loader 全矩阵、final-overlay Iris 路径行为不变。
