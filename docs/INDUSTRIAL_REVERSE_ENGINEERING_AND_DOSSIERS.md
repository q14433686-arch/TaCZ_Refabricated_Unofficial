# 弹药逆向工程与稳定工艺档案委托

## 目标

本轮不替换既有的四槽弹药装配机、弹药批量、推进药平衡、弹壳回收或爆炸战斗部链。
新增的是两条**知识／工装取得**路线：

1. 从实际弹药证据逆向口径量规；
2. 用稳定的层级档案包在枪械工作台委托指定原始工艺档案。

它们分别解决“必须先有样枪才能做弹药工装”和“高级指定档案只能赌随机箱子”的问题。

## 口径量规来源

所有路线先消耗一枚 `中性弹药基准量规毛坯`；样本逆向是破坏性分析，完整样枪是非破坏性测绘。

| 证据 | 输出 | 可校准 | 样本是否消耗 |
| --- | --- | --- | --- |
| 对应完整样枪 | 完整口径基准量规 | 弹壳模具、弹头模具 | 否 |
| 无默认样枪的机械合成 datum | 完整口径基准量规 | 弹壳模具、弹头模具 | 原料消耗 |
| 一发完整散装弹 | 完整口径基准量规 | 弹壳模具、弹头模具 | 是，1 发 |
| 新弹壳 | 弹壳尺寸量规 | **仅弹壳模具** | 是，1 个 |
| 已击发弹壳 | 弹壳尺寸量规 | **仅弹壳模具** | 是，1 个 |
| 弹头芯 | 弹头外形量规 | **仅弹头模具** | 是，1 个 |

因此弹壳不会不合理地证明弹头型号，弹头也不能反推壳体尺寸；完整弹、样枪或明确的无枪 datum 才能校准两枚模具。

RPG 没有可抛出的已击发壳，但可从发动机壳体、HEAT 战斗部芯或完整火箭样本建立对应量规。40 mm 也保留完整弹、弹壳和高爆弹头芯的证据路径。

## 稳定档案委托

当前箱子和村民给的是随机具体 `master` 档案，样枪测绘则需要先有样枪。现在每个制造层级新增一种可稳定制造的档案包：

```text
legacy    野战档案包
service   制式档案包
advanced  现代技术档案包
precision 受限精密档案包
```

档案包通过 Basin 或机械合成器制造，层级越高要求越高。玩家随后在**默认枪械工作台的杂项页**选择一条明确的“工艺档案委托”配方：

```text
层级档案包                    消耗
空白工装页                    消耗
对应动作夹具                  保留
→ 选定平台的 master 原始工艺档案
```

这是一项明确的 GUI 委托选择，不是多个相同 Basin/传送带输入竞争不同输出。玩家选择的 dossier 条目就是型号选择；物理材料只表示档案等级和实际动作夹具证据。

探索、村民随机具体档案和样枪测绘仍然保留：它们是更快或更便宜的捷径。稳定委托是保底路线，尤其让 advanced / precision 平台不会永久被箱子运气锁死。

## 后续工艺

委托获得的 `master` 档案仍走既有链：

```text
master 原始档案 + 空白工装页
→ production 平台工装模板
→ 模具 / 量规 / 外装校准
→ 组件与终端总装
```

旧版蓝图仍可用 `restore_template_<platform>` 转换为 production 模板；已有组件模、弹壳模和弹头模不报废。
