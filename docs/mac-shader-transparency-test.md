## 背景（一句话）

之前 Mac 上「TACZ + 光影（Iris）」会导致地形/世界透明。现在修了一版，需要在 Mac 真机上验证修好没有。

## 一、准备工作

1. 保持你**之前出现问题的那一套环境不动**（MC 26.2、Fabric Loader、Iris、Sodium、光影包），只把 TACZ 的 jar 换成测试版。
2. 光影包优先用之前出问题的那个（Complementary、Bliss 等都行，用哪个记下来告诉我们）。
3. 准备一个能进的世界，背包里放一把**带倍镜的枪**。
4. 确认你的芯片型号（苹果菜单 → 关于本机，如 Apple M4），记下来。

## 二、最低限度测试（2 分钟，只回答"修好没"）

时间紧的话，只做这一步，不用改任何设置、不用碰日志：

1. 换上测试版 jar，进游戏（**什么设置都不用改**，默认就是新修复）。
2. 打开光影，进世界，拿出枪，看地形：正常还是透明？
3. F2 截一张图。
4. 发回四样：截图 + 芯片型号 + 光影包名字 + "好了"/"没好"一句话。

就这些。能回答"修好没"的就是这一组数据。
愿意多花 10 分钟的话，继续往下做完整三档（第四节）——那是用来确认"修的原因对不对"的。

## 三、档位在哪里（完整测试用）

游戏内：Mod Menu → 找到 TACZ → 打开它的设置（Cloth Config）→ **渲染** → **Iris 瞄具掩码注入范围**（英文界面：Render 分类下带 Iris Scope Mask 字样的下拉框）。

它有三个值：`HAND_ONLY`（默认）、`ALL`、`OFF`。

⚠️ **每次改完档位，必须重载光影包才生效**：打开 Iris 光影包界面重新点一下 Apply（或退到标题画面再进世界）。

## 四、三档测试（完整版）

三档**每一档**都做下面同一套动作（第一档 HAND_ONLY 是默认值，不用改，直接进游戏）：

1. 确认档位对 → 重载光影包（第一档不用）→ 进入世界。
2. 站到一个**能同时看到地形和枪**的位置，记下来（之后两档站同一个位置）。
3. 看地形：**正常还是透明**？按 F2 截图。
4. 拿起倍镜枪**开镜一次**：瞄具里的遮罩圈是否正常显示？（正常/不正常，记下来）
5. **完全退出游戏**，到游戏目录 `logs/` 里把 `latest.log` 复制一份，改名保存：
   - 第一档 → `HAND_ONLY.log`
   - 第二档 → `ALL.log`
   - 第三档 → `OFF.log`

顺序建议：HAND_ONLY → ALL → OFF。

### 为什么三档都要测

三档回答的是三个不同的问题，少一档，结论就不完整，可能要麻烦你补测一次：

- **HAND_ONLY**：新修复有没有把地形修好？
- **ALL**：旧行为是不是仍然透明？（确认我们修的正是这个原因）
- **OFF**：把注入整个关掉后还透不透？（确认没有别的原因）

## 五、测完发回什么（完整版）

打包发给维护者，一共 8 样：

- 3 张游戏截图（每档 1 张，同一位置）
- 3 个日志文件（`HAND_ONLY.log`、`ALL.log`、`OFF.log`）
- 你的芯片型号 + 光影包名字
- 每档一句话：地形正常/透明、开镜遮罩正常/不正常

日志不用筛、不用懂，直接发整个文件就行。关键行我们自己会找。

## 六、可选进阶（愿意再跑一遍的）

这步不做也不影响结论，做了能帮我们二次确认：

1. 完全退出游戏。
2. 在游戏目录找到 TACZ 的客户端配置文件 `tacz-client.toml`（一般在 `config/` 或 `tacz/` 文件夹里），用文本编辑器打开。
3. 找到 `ScopeMaskDebug = false` 改成 `true`，保存。
4. 重进游戏，只跑 HAND_ONLY 那一档，把 `latest.log` 发回。
5. 测完可以把那行改回 `false`。

注：开了这个开关后屏幕角落可能多一个小预览窗，那是诊断信息，不是 bug。

## 七、FAQ

- **改了档位感觉没变化？** 十有八九是忘了重载光影包。重载后再看。
- **游戏崩溃 / 进不去？** 把 `crash-reports/` 里最新的崩溃报告 + `latest.log` 一起发回，并注明当时是哪个档位。
- **开镜遮罩在 OFF 档下消失？** 正常。OFF 就是把注入整个关掉，遮罩没了是预期行为，只要地形正常就行。
- **某一档地形一半正常一半透明？** 截图 + 详细描述看到的样子，这种结果同样重要。

## 八、结果怎么看（维护者用）

| HAND_ONLY | ALL | OFF | 结论 |
|---|---|---|---|
| 地形正常 | 地形正常 | 地形正常 | 修好，结案 |
| 地形正常 | 透明 | 地形正常 | 主修复成立，C-2 那层要回头查 |
| 地形正常 | 透明 | 透明 | 存疑：OFF 还透明说明另有原因，假说需重审 |
| 透明 | 透明 | 透明 | 修复无效，假说证伪，回分析侧 |
